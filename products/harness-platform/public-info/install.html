Подключение магазина

Добавьте магазин в разделе «Интеграции» в меню чата. Для каждого подключения можно задать название, чтобы различать магазины в чате.

Ozon

Продажи и операции магазина · Seller API

  1. Откройте настройки API в Ozon Seller. Скопируйте Client-Id продавца и создайте Api-Key с доступом на чтение нужных отчётов.
  2. В «Интеграциях» выберите Ozon. Заполните поля Client-Id и Api-Key продавца.

Реклама · Performance API

Для данных рекламных кампаний создайте API-клиент в рекламном кабинете Ozon и заполните отдельную пару полей Performance — Client ID и Client Secret. Для одного магазина можно сохранить оба подключения.

Wildberries

  1. В кабинете продавца откройте управление API-токенами.
  2. Создайте токен с правами на чтение. Выберите категории для нужных отчётов, например «Статистика» для заказов и продаж.
  3. В «Интеграциях» выберите Wildberries и вставьте токен в форму.

Проверка и первый вопрос

Нажмите «Сохранить подключение», затем «Проверить». Если доступ отклонён, проверьте реквизиты и права ключа в кабинете площадки. Откройте личный чат, выберите нужное подключение и спросите, например, «Сколько было заказов на Wildberries вчера?»
