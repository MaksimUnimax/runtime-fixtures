# Иллюстрации

## Техническое задание

Пользователь открывает «Плагины → Графика», подключает «Иллюстрации» к текущему чату и открывает настройки плагина из левого меню. В настройках он выбирает генератор из каталога своего сервиса OpenRouter. Варианты сгруппированы по производителю. Список учитывает доступ ключа и поддержку Image API.

Основная модель получает инструмент создания иллюстраций. Подтверждённый файл прикрепляется к ответу в исходном чате. Владелец может открыть его после перезагрузки. Модель действия хранится в рабочем пространстве независимо от публикаций администратора и личного выбора модели чата. Авторизация проверяется на том чате, откуда пришёл вызов. Квитанция генератора учитывается отдельной попыткой в операции сообщения.

## Роадмап и приёмка

| Этап | Проверка результата |
|---|---|
| Подключение | Переключатель, кнопка в левом меню, сохранение выбора после обновления страницы |
| Генератор | В списке доступны только модели ключа с поддержкой выдачи изображения через Image API |
| Ответ | DeepSeek вызывает выбранную модель, пользователь видит файл в истории исходного чата |
| Учёт | Стоимость генератора и вызовы основной модели сходятся с суммой операции |
| Отказы | Отмена при 429 освобождает резерв. Обрыв с неизвестным результатом помечается для сверки. Повтор операции защищён от второго списания и вложения |
| Независимость | Личный и общий выбор основной модели сохраняют явно настроенный генератор |
