# Плагины Octoport

## ТЗ

Пользователь открывает «Плагины» в левом меню чата. Каталог показывает дерево категорий, описание каждого доступного плагина и переключатель для текущего диалога. Сразу после подключения название появляется в отдельном списке «Подключённые плагины» в левой панели прямо над «Настройками». Нажатие на название открывает настройки плагина. При свёрнутой панели доступны кнопки со значками и названиями для программ чтения с экрана. Переключение чатов обновляет список. После перезагрузки выбор восстанавливается с сервера. Гость видит форму входа и гостевой чат.

Каталог и настройки используют окно, крестик, кнопки и переключатели закреплённой версии DeepSeek Harness. Крестик справа вверху и Esc закрывают окно. Нажатие на заголовок категории раскрывает и сворачивает её. Эти действия доступны в светлой и тёмной темах.

У категории есть стабильный идентификатор и родитель. Первые разделы — аналитика, реклама, графика и документы. Реестр серверных плагинов расположен в `platform_core/user_plugins/registry.py`. Право пользователя и выбор чата хранятся в существующих таблицах `entitlements` и `chat_plugins`. Настройки отдельного магазина принадлежат подключению аккаунта. Модель получает только инструменты и данные магазинов, разрешённых в текущем чате.

## Общая матрица

У WB и Ozon один каталог и один инструмент чата `marketplace_report`. Исполняемая версия находится в `platform_core/marketplace_matrix/`. Базовые шаблоны и источники поставляет `runtime.tar.gz`, закреплённый по SHA-256. В том же пакете регистрируются шаблоны, использующие настройки плагинов. Изменение общего шаблона доставляется обеим площадкам одним выпуском. Для каждой пары «шаблон, подключение» каталог проверяет площадку и тип доступа. Обработчик повторно проверяет принадлежность подключения чату перед чтением.

Внутренние вызовы модели используют платёжный шлюз Octoport. Плагин наследует общую модель либо хранит выбранную владельцем аккаунта пару «модель, рассуждение». Список поддерживаемых моделей приходит из рабочего шлюза. Модели доступны задания выбора источников. Проверка отчёта, вычисление и запись чисел выполняются на сервере.

## Плагины и роадмап

| Плагин | Назначение | ТЗ и этапы |
|---|---|---|
| Вайлдберис | Отчёты общей матрицы, каталог товаров и коэффициенты магазина или артикула | [ТЗ](wildberries/SPEC.md) · [Роадмап](wildberries/ROADMAP.md) |

Для следующего плагина создаётся свой каталог документации с ТЗ и роадмапом, серверный обработчик, карточка каталога и панель настроек. Для Ozon повторно используется общая матрица. Графики, PDF, таймер и связь через Telegram — направления следующих плагинов.


## Приёмка изменений

Перед сдачей сверить общие требования с этой страницей и требования каждого затронутого плагина с его ТЗ и роадмапом. Для каждого пункта в отчёте указать действие, фактический результат и среду проверки. Пользовательский путь проходить в Chromium через обычные кнопки, включая повторное открытие страницы. Указать происхождение данных для расчётов. Если проверка выявила ошибку, исправить причину и повторить проверку. Каждый отчёт владельцу включает список пройденных пунктов и статус оставшихся.
