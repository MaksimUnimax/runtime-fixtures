# Плагины Octoport

## ТЗ

Пользователь открывает «Плагины» в левом меню чата. Каталог показывает дерево категорий, описание каждого доступного плагина и переключатель для текущего диалога. После подключения отдельная кнопка слева открывает настройки. Переключение чатов обновляет набор кнопок. Гость видит форму входа и гостевой чат.

У категории есть стабильный идентификатор и родитель. Первые разделы — аналитика, реклама, графика и документы. Реестр серверных плагинов расположен в `platform_core/user_plugins/registry.py`. Право пользователя и выбор чата хранятся в существующих таблицах `entitlements` и `chat_plugins`. Настройки отдельного магазина принадлежат подключению аккаунта. Модель получает только инструменты и данные магазинов, разрешённых в текущем чате.

## Общая матрица

У WB и Ozon один каталог и один инструмент чата `marketplace_report`. Исполняемая версия находится в `platform_core/marketplace_matrix/`. Базовые шаблоны и источники поставляет `runtime.tar.gz`, закреплённый по SHA-256. В том же пакете регистрируются шаблоны, использующие настройки плагинов. Изменение общего шаблона доставляется обеим площадкам одним выпуском. Для каждой пары «шаблон, подключение» каталог проверяет площадку и тип доступа. Обработчик повторно проверяет принадлежность подключения чату перед чтением.

Внутренние вызовы модели используют платёжный шлюз Octoport. Плагин наследует общую модель либо хранит выбранную владельцем аккаунта пару «модель, рассуждение». Список поддерживаемых моделей приходит из рабочего шлюза. Модели доступны задания выбора источников. Проверка отчёта, вычисление и запись чисел выполняются на сервере.

Для следующего плагина создаётся свой каталог документации с ТЗ и роадмапом, серверный обработчик, карточка каталога и панель настроек. Для Ozon повторно используется общая матрица. Графики, PDF, таймер и связь через Telegram — направления следующих плагинов.
