# Вайлдберис

**Категория** — Аналитика. **Область действия** — магазины WB, разрешённые в выбранном чате. Обычные отчёты Ozon и WB обслуживает общая матрица Octoport.

## Сценарий

1. Открыть «Плагины», включить «Вайлдберис» и нажать его название слева. При обычном подключении магазина WB к диалогу плагин включается автоматически. У уже подключённых чатов сохраняется доступ к прежним отчётам.
2. Выбрать магазин из подключений аккаунта. При добавлении запускается загрузка всех страниц активного каталога WB Content API. Форма показывает артикул WB (nmID), название и артикул продавца. Один nmID объединяет размеры этой карточки.
3. Оставить «Весь магазин» либо выбрать товар. В редакторе видны только значения выбранной области. Оператор вводит число и нажимает «Сохранить», либо задаёт интервал и нажимает «Рассчитать» рядом с показателем. Кнопка «За год» выбирает последние 365 завершённых дней по Москве.
4. Автоматический расчёт оплачивается через шлюз моделей и фиксирует модель, период, исходные суммы, дату и результат. При ручном вводе сохраняются дата и источник «Вручную». Значение 0 допустимо. Если другой оператор изменил показатель во время расчёта, прежний запрос завершится конфликтом и сохранится более новая правка.
5. В запросе к расчётному шаблону сервер выбирает значение каждого коэффициента для nmID, затем при необходимости значение магазина. В ответе указана область каждого значения. Расчёт повторяется по отдельной команде из настроек. Отключение плагина закрывает его отчёты в этом чате. Последующее включение возвращает разрешённые магазины. Явное отключение магазина в форме отзывает доступ к нему в текущем чате.

## Коэффициенты и источники

| Показатель | Формула | Единица |
|---|---|---|
| Доля потерь | 100 × сумма cancelCount / сумма orderCount по одной когорте из воронки WB. Возвраты уже входят в cancelCount. | % |
| Прямая доставка | Сумма deliveryService для «К клиенту при продаже» и «К клиенту при отмене» / исходно заказанные единицы | ₽ за заказанную единицу |
| Обратная доставка | Сумма deliveryService для «От клиента при отмене» и «От клиента при возврате» / сумма returnAmount по этим событиям | ₽ за обратное событие |
| Поправка к комиссии | 100 × (фактическая комиссия − комиссия по историческим официальным ставкам) / подписанный оборот продавца | процентные пункты |

Для комиссии берутся продажа, возврат и коррекция продаж. Для каждой строки фактическая комиссия равна retailPriceWithDisc − forPay − acquiringFee. Возврат имеет отрицательный знак. Для официальной комиссии применяются категория, схема FBS/FBW и тариф на дату заказа. Если WB пропустил схему, оператор может подтвердить соответствие «название склада → FBS или FBW» в настройках. Применённые соответствия сохраняются вместе с результатом. Коррекция с нулевой ценой может изменить фактическую комиссию. Для отчёта по товару формулы применяются к его строкам. Результаты логистики — оценки на основе окна финансовых событий и когорты заказов за тот же период.

Архив в общей матрице содержит проверенные интервалы из опубликованных таблиц WB и датированные снимки официальных тарифов. Снимки за 15–21 ноября 2026 года содержат 7 417 категорий в день. Настройка `OCTOPORT_WB_TARIFF_HISTORY` указывает на полный обновляемый JSON-архив того же формата (период действия, источник, ставки по категории и схеме). Цены из новых тарифов применяются к покрытым ими датам. При неизвестной ставке, схеме доставки или нулевом знаменателе форма объясняет, каких данных не хватает. Можно выбрать другой период или ввести собственное значение.

## Использование в матрице

Шаблон сохранённых коэффициентов читает текущие значения. Шаблон прогноза заказов использует исходное количество N, долю потерь k в долях, прямую доставку L и обратную доставку R. Ожидаемое сохранённое количество равно N × (1 − k), прямая доставка равна N × L, обратная равна N × k × R. При подтверждённых цене P и официальной ставке b ожидаемая комиссия равна N × (1 − k) × P × (b + Δ) / 100. При неполных входах выводятся доступные части прогноза. Фактические продажи, комиссии и логистика из обычных отчётов остаются фактическими величинами.
