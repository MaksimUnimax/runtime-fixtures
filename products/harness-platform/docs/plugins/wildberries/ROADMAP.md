## Проверка 21 ноября 2026

В Chromium пройдены включение из каталога, быстрый вход слева, добавление магазина, автоматическая загрузка товаров, ручной ввод отдельно для магазина и nmID, смена области и повторное открытие страницы. Тесты API и матрицы проверяют сохранённый ноль, одновременное присутствие WB и Ozon, отзыв доступа, восстановление выбранных магазинов, конфликт записей, продолжение после 429 и повтор того же платного запроса. В изолированной проверке рабочая модель через платёжный шлюз вызвала шаблоны потерь и поправки комиссии. Формулы дополнительно сверены с ранее собранным годовым отчётом. Для одной строки комиссии потребовалось явное подтверждение схемы склада.

## Приёмка каталога и левого меню · 21 ноября 2026

| Требование | Действие и фактический результат |
|---|---|
| Каталог в стиле DeepSeek Harness | Chromium показал четыре категории, описание WB и штатный Switch. «Аналитика» закрылась и открылась повторным нажатием. |
| Закрытие | Крестик в правом верхнем углу закрыл каталог и настройки WB. Esc закрыл оба окна. |
| Список слева | Включили WB в каталоге. В отдельной группе «Подключённые плагины» над «Настройками» появилось название. Нажатие открыло WB. После отключения строка исчезла. |
| Обычное подключение магазина | Выбрали магазин WB через «Подключения» над полем сообщения. Без перезагрузки появилась строка WB, в настройках уже был выбран этот магазин. Явное отключение магазина вернуло кнопку подключения. |
| Область чата | После обновления страницы сохранились плагин и значение магазина. В другом чате WB был выключен. При возвращении в первый чат кнопка была доступна. |
| Виды панели и темы | В свёрнутой панели настройки WB открылись по значку. На экране 390 × 700 открыли боковое меню, каталог и закрыли окно крестиком в тёмной теме. |
| Каталог и области расчёта | Магазин и карточки получены из тестового API. Загрузились 101 карточка за две страницы в тесте источника. В Chromium сохранили 12 для магазина и 0 для товара; смена области вернула нужное значение. |
| Период, склад и модель | В форме четыре показателя с кнопкой расчёта. «За год» установила 365 завершённых дней. Сохранились схема склада FBW, выбранная тестовая модель с уровнем off и возврат к общей модели. |
| Формулы, доступ и повторы | Тесты серверной части проверили четыре формулы, выбор отдельного SKU, наследование параметров магазина, конфликт версий, отзыв доступа и продолжение после 429 с одним обращением к модели. |
