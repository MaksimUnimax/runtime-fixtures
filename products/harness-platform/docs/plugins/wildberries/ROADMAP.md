# Вайлдберис · роадмап

| Этап | Приёмка |
|---|---|
| Каталог и доступ | Категория «Аналитика», карточка «Вайлдберис», переключатель для чата, быстрый вход в настройки, перенос существующих разрешений WB |
| Магазины и товары | Несколько подключений; полная пагинация карточек; отдельно магазин и выбранный nmID; повторное открытие показывает сохранённые значения |
| Сбор и настройка | Для каждого из четырёх показателей доступны ручной ввод и расчёт за указанный интервал; модель наследуется либо выбирается из доступного списка; 429 возобновляет чтение |
| Матрица | Один инструмент WB/Ozon, допустимые магазины для каждого шаблона, серверный выбор значений SKU/магазина, явная отметка об отсутствующих входах |
| Приёмка интерфейса и данных | Проверить на тестовом аккаунте включение/отключение, форму магазина/SKU, конкурирующие изменения и прогноз. На данных владельца сверять годовые суммы с выгрузками WB по тому же интервалу |
| Следующие итерации | Расширять покрытие исторических тарифов и способов подтверждения схемы доставки; новые составные шаблоны выпускать через общую матрицу |

## Проверка 21 ноября 2026

В Chromium пройдены включение из каталога, быстрый вход слева, добавление магазина, автоматическая загрузка товаров, ручной ввод отдельно для магазина и nmID, смена области и повторное открытие страницы. Тесты API и матрицы проверяют сохранённый ноль, одновременное присутствие WB и Ozon, отзыв доступа, восстановление выбранных магазинов, конфликт записей, продолжение после 429 и повтор того же платного запроса. В изолированной проверке рабочая модель через платёжный шлюз вызвала шаблоны потерь и поправки комиссии. Формулы дополнительно сверены с ранее собранным годовым отчётом. Для одной строки комиссии потребовалось явное подтверждение схемы склада.
