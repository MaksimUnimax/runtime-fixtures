# Озон

Плагин категории «Аналитика» подключается к текущему чату. Каталог, переключатель, быстрый вход над «Настройками», крестик, Esc и мобильное меню используют тот же интерфейс DeepSeek Harness, что и «Вайлдберис». В одном чате можно включить обе площадки. Обычное подключение магазина Ozon включает его плагин. Выбор хранится по чатам.

В настройках видны магазины Ozon аккаунта. Для чтения товаров и расчётов нужны Client-Id и Api-Key Seller API. Рекламное подключение Performance сохраняет свой доступ к рекламным отчётам. При замене ключа того же Client-Id каталог обновляется. Для другого Client-Id добавляется отдельный магазин со своими коэффициентами. При добавлении магазина каталог запрашивает все страницы товаров и сведения о карточках. Область расчёта — весь магазин либо выбранный Ozon SKU. Можно искать по названию, артикулу продавца и SKU. Значение магазина и значение SKU редактируются раздельно.

| Показатель | Расчёт | Хранение |
|---|---|---|
| Доля потерь | Уникальные отменённые, невыкупленные и возвращённые единицы заказов FBO и FBS / исходно заказанные единицы × 100. Отмена и возврат одного экземпляра учитываются один раз. | % |
| Прямая и последняя доставка | Подтверждённые чистые расходы на прямую и последнюю доставку / исходно заказанные единицы. Заказы учитываются по дате обработки, расходы — по дате начисления. Для SKU требуется товарная детализация расходов. | ₽/заказанную единицу |

Для каждого показателя оператор может ввести число вручную или запустить расчёт за завершившийся интервал. «За год» выбирает последние 365 завершённых дней по Москве. Ноль сохраняется как значение. При отсутствии знаменателя или подтверждения источника форма объясняет причину и сохраняет прежнее значение. Сохраняются происхождение, даты, период и основание расчёта. Внутренняя модель наследуется от Octoport или выбирается из доступного списка вместе с уровнем рассуждения.

Единая матрица обслуживает WB и Ozon. В расчёте по SKU используется его сохранённая настройка и затем, при отсутствии, настройка магазина для каждого показателя отдельно. Отключение плагина отзывает доступ к отчётам его площадки в этом чате. Стоимость обратной доставки Ozon определяется отдельно тарифом товара и схемы. Годовая поправка комиссии WB относится к «Вайлдберис».

## Повтор после HTTP 429

Все чаты с подключённым плагином используют общую политику для безопасно повторяемых чтений. Продолжительность паузы задаёт Retry-After из текущего ответа (секунды или HTTP-дата). При нуле или уже наступившей дате повтор разрешён сразу. Если заголовок отсутствует или его невозможно разобрать, пауза составляет 7 секунд. Это действует для всех методов, включая загрузку каталога и чтение профиля продавца. Ограничения на количество повторов в Октопорте нет. Повтор действует в рамках исходной операции, с повторной проверкой прав. Принятый ответ завершает цикл.

В ходе работы над ответом отображаются метод, причина, длительность ожидания и номер каждого фактически отправляемого повтора. События не добавляют сообщений в диалог и не вызывают модель. При переподключении вкладка получает последние 12 событий активного запроса.
