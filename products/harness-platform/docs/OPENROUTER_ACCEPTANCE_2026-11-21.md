Для проверки интерфейса использовали Chromium. На octoport.ru обычный пользователь выбрал модель, подключил плагин, сохранил генератор и получил ответ с нулевым балансом. ## Что исправили по результатам прогонов

- Каталог пропускал ID с префиксом «~» и предлагал три генератора, которых не обслуживал выбранный Image API. Исправлены разбор ID и проверка возможностей по двум каталогам.
- При чтении сохранённого коэффициента магазина обработчик требовал пустой объект параметров. Модель также могла воспроизвести сокращённое имя инструмента. Теперь каталог передаёт точные разрешённые ID и примеры, а чтение настроек всего магазина допускает отсутствие параметров. У отчётов сохранилась проверка обязательных полей.
- Генератор создал PNG, но инструмент не вернул агенту корректное представление результата. После этой правки браузер всё ещё показывал недоступное превью. Исправлены ответ инструмента и показ сохранённого, доступного владельцу изображения в истории чата.

## Как читать журнал

В таблице 34 пользовательские операции и 68 попыток вызова моделей. 25 операций дали ожидаемый результат. Восемь строк фиксируют ошибки промежуточных сборок, одна — ожидание занятой бесплатной модели, завершённое отзывом тестовой сессии. Сумма списаний по этим 34 операциям составляет 15,078284274372 монеты, включая прогоны до исправлений. Сетевые пробы и запросы каталога в эту сумму не входят.

В столбце времени клиента записано время от отправки до получения ответа либо отмены. Для одного следующего сообщения после рисунка журнал сохранил только время работы агента. Пустой ID генерации означает, что поставщик не вернул ID. Вызовы генератора всё равно связаны с операцией чата по внутреннему ID попытки и содержат фактическую стоимость из ответа. Сумма резервов разных попыток не равна списанию.

Общий выбор для действующих клиентов в ходе приёмки не публиковали. Для проверки глобальной смены, отказов, платной генерации и переключения адресов использовали изолированные аккаунты и рабочие маршруты. Матрица WB и Ozon по всем шаблонам остаётся отдельной отложенной приёмкой.
