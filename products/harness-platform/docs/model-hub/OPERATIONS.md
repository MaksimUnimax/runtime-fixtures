# Работа оператора хаба

Откройте «Администрирование → Хаб моделей». «Требуются ключи» показывает модели, для которых в хабе ещё нет ключа ни одного известного прямого поставщика. Варианты для одной модели взаимозаменяемы на этапе регистрации. Новая неизвестная модель появляется в кандидатах для исследования.

Выберите поставщика, укажите узнаваемую метку и введите секрет. Повторная запись под той же меткой заменяет ключ. Секрет шифруется на сервере существующим хранилищем установки. В списке остаются только поставщик и метка. Статус «Ключ сохранён» подтверждает сохранение. Для допуска к клиентскому трафику нужна отдельная прямая проверка.

Каталог обновляется службой octoport-hub-catalog каждые 15 минут. Кнопка «Обновить показания» перечитывает состояние сервера. При отказе каталога на экране остаются последний успешный снимок, время попытки и причина сбоя.

Исследователь запускается командой `python -m platform_core.hub_research --database <путь-к-БД-хаба>` из каталога продукта. Он передаёт второй серверной авторизации Codex до четырёх публичных ID за запуск. Источники перепроверяются через семь дней. При сбое последняя успешная проверка сохраняется. Вывод исследователя носит справочный характер. Он не может изменить цену, разрешить маршрут, получить ключ из формы или выполнить запрос маркетплейса.

Обе команды и веб-приложение должны использовать одну базу. В поставляемых unit-файлах это /var/lib/octoport-model-hub/model-hub.sqlite3. Для веб-службы задайте HARNESS_MODEL_HUB_DATABASE с этим путём и StateDirectory=octoport-model-hub дополнительно к существующему каталогу состояния. По умолчанию тестовое приложение ищет базу рядом с базой аккаунтов. Таймер исследования запускается каждые 30 минут. Команда каталога выполняется от пользователя приложения. При запуске исследователя с правами владельца профиля файл базы должен быть предварительно создан сервисным пользователем. Профиль codex2 уже авторизован на узле 80. При недоступной авторизации проверять статус штатной командой `codex2 login status`.

Приёмка прямых адаптеров, статистики ключей и автоматического переключения описана в [дорожной карте](ROADMAP.md).
