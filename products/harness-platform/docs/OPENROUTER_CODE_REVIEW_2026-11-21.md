## Что остаётся открытым

1. **Высокий приоритет. Возобновление после остановки процесса.** В SQLite хранится срок повторной попытки. Исходные сообщения, состояние цикла инструментов и задание, которое новый процесс мог бы подхватить перед генерацией, не сохраняются в возобновляемом виде. Подтверждённый 429 повторяется при работающем процессе. После его жёсткого завершения автоматического продолжения этой же операции нет. При известном ID уже принятой генерации финансовая сверка восстанавливается. Для закрытия пункта 6 ТЗ нужен тест с принудительным завершением процесса до и после принятия запроса и отдельной проверкой количества внешних вызовов.
2. **Средний приоритет. Диагностика в админке.** Видны состояние ключа, время загрузки каталога и расходы по операциям. Общий показатель последней успешной генерации с временем и последним результатом отдельно не выводится. Для ряда отказов ключа, баланса OpenRouter и транспорта чат получает общую ошибку. Пункт 7 ТЗ выполнен частично.
3. **Средний приоритет. Долгое ожидание при перегрузке.** При локальном исчерпании слотов ожидающие клиенты повторно проверяют доступ раз в секунду. Порядок поступления не гарантирован. При непрерывной конкуренции верхняя граница ожидания отдельного клиента не доказана. Испытание на длительную конкурентную нагрузку в этот аудит не входило.
4. **Ограничение Image API.** Для текстового вызова отправляется `provider.max_price`. В использованной схеме `POST /api/v1/images` отсутствует эквивалентный потолок. Между свежей проверкой и ответом может измениться внешняя цена. Лимит списания покупателю соблюдает кошелёк, а разница требует сверки и может стать расходом сервиса.
5. **Эксплуатация.** На системном разделе Easyscript при двух замерах оставалось 882–908 МиБ, на узле приложения свободно 64 ГиБ. Оба роутера были в работе. Заполнение раздела угрожает записи журналов и обновлениям. Удаление серверных данных в ходе ревью не выполнялось.
6. **Зависимости.** В установленном дереве есть опубликованные уведомления. Версии, границы проверки и список приведены ниже. Перенос на новые версии SDK и повторная проверка совместимости остаются открытыми.
