Как получить токен
  1. Войдите в Яндекс с аккаунтом, у которого есть доступ к счётчику $counter.
  2. В Яндекс OAuth создайте приложение «Для доступа к API или отладки» и добавьте право metrika:read. Если форма запрашивает Redirect URI, укажите https://oauth.yandex.ru/verification_code.
  3. Скопируйте ClientID из приложения и замените ВАШ_CLIENT_ID в адресе https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID.
  4. Откройте полученный адрес, подтвердите доступ и вставьте токен из Яндекса в поле выше.
