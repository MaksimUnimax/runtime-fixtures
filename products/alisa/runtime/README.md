# Runtime Алисы

Канонический исходник текущего исполняемого ядра перенесён из установленной версии `20261106-store-check-6098-r1`. `BASE_INSTALLED_MANIFEST.json` фиксирует все 74 исходных файла; перенос не добавляет боевую конфигурацию, ключи или базы. Старые пакеты в docs сохраняются как доказательства своих версий, но новые исправления ядра выполняются здесь.

`python run_checks.py --output ../dist/runtime-qualification.json` проверяет сохранённые сценарии, очередь, локальный HTTPS/Unix и сроки ожидания. Это не доказательство численной корректности реальных API или установки на сервер.

`python build_package.py --source <полный SHA> --output ../dist` упаковывает только committed файлы этой директории с хешами. Пакет платформы не устанавливает это ядро автоматически.

A03 добавляет совместимые колонки dispatch_order и queue_order; исходные job/session/result не заменяются. Перед установкой требуется SQLite backup и проверка upgrade/rollback на одноразовой копии. A06 ограничивает общее ожидание HTTP, не повторяет неизвестные запросы. Одновременно допускается не более четырёх I/O-потоков; зависший DNS удерживает свой слот до выхода и после отмены не отправляет запрос. При полностью зависшем DNS восстановление всех слотов может потребовать штатного перезапуска службы.
