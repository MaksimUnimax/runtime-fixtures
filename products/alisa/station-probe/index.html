Октопорт маркет · проверка колонки

Автоматический ответ

Здесь проверяем доставку с сервера. Сценарий для выбранной колонки создастся автоматически. Финансовые данные в проверке не используются.

Проверяю ссылку…

1. Подключите Яндекс

Используйте аккаунт, к которому подключена колонка и которому доступен навык «Октопорт маркет». Вход подтверждается на стороне Яндекса. Пароль здесь не вводится.

Открыть подтверждение Яндекса на телефоне

2. Выберите колонку

3. Проверьте автоматическую речь

После нажатия ничего не говорите колонке. Через 15 секунд сервер сам отправит команду.

Ожидается: «Автоматическая доставка Октопорта работает. Контрольное число сто двадцать три».

Ожидается: «Связь с учебным сервером работает. Контрольное число сто двадцать три».

Сначала проверьте контрольную фразу, затем запуск навыка. Сообщение об отправке команды ещё не подтверждает звук — проверьте, что произнесла сама колонка.

    Подключение временное: до трёх часов. Отключение очищает сессию на сервере. Созданный технический сценарий не запускается повторно сам по себе.
