# STATION-PROBE-R1 — установленная проба транспорта

8 ноября 2026. Шаги S06/S18. **INSTALLED / QR_AUTHOR_TESTED / OWNER_AUDIO_NOT_RUN**.

## Что сделано

На https://alice-lab.octoport.ru/station-probe/ установлена отдельная временная
страница проверки колонки. Для доступа владельцу выдана ограниченная ссылка;
её секретная часть в Git не сохраняется. Страница позволяет подтвердить вход
через QR Яндекса, выбрать колонку из своего аккаунта и запустить через15секунд
две фиксированные безопасные проверки: TTS с контрольным числом123 и вызов
«Спроси Октопорт маркет проверка связи». Собственный технический сценарий
создаётся автоматически при проверке, ручного конструктора нет.

Сессия только в памяти до3часов, пароль/токен в чат не нужен. У страницы отдельный
capability-доступ и строгий Origin. Только фиксированные команды, сериализованные
действия по выбранной колонке; мутации не повторяются при неизвестном исходе.
Отзыв очищает сессию и отменяет ожидающие команды; уже отправленную команду
отозвать нельзя. Созданный служебный сценарий остаётся без автоматических
триггеров времени; неизвестный исход создания не приводит к слепому повтору.

## Что ещё НЕ принято

Подтверждённые cookies→Quasar, список настоящих колонок, автоматическое создание
сценария, реальный звук, запуск приватного навыка с правильным аккаунтом,
продолжение беседы. Проба не подключена к финансовой очереди и не является
полным onboarding нового клиента. Внешний Quasar API неофициальный.

Приветствие проверено как кандидатная функция, но **не установлено**. На сайте
источник имени существует: Customer.display_name и account/me→profile.display_name.
Старая лабораторная привязка навыка принимает demo-a/demo-b; проверенной связи с
Customer сайта нет. Нельзя подставлять имя Яндекса/email или произвольно связывать
аккаунты. Для «Привет, {имя сайта}» нужен проверенный S06 voice→Customer read path.
H00 уже существует отдельно; новый текст помощи не придумывать.

## Проверка владельца

1.Открыть выданную в чате временную ссылку на компьютере.
2.Нажать «Получить QR для входа», подтвердить на телефоне нужный Яндекс-аккаунт.
3.«Показать мои колонки» → выбрать свою → «Использовать эту колонку».
4.«Через15секунд произнести контрольную фразу». Ничего не говорить колонке.
  Ожидается «Автоматическая доставка Октопорта работает. Контрольное число сто
  двадцать три».
5.«Через15секунд запустить наш навык». Ожидается нынешняя безопасная фраза
  «Связь с учебным сервером работает. Контрольное число сто двадцать три».
6.Сообщить, что реально произнесла колонка на каждом шаге. HTTP accepted не
  считается фактически услышанной речью.
