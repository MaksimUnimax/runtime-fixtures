# tooling/api-watch

Получение официальных спецификаций, semantic inventory/diff и candidate evidence по READ_POLICY. Не auto-enable и не production patch.

Код включает получение источников, снимки и сравнения, сопоставление с операциями расширения, отчёты и инциденты. Наличие этих модулей не доказывает приёмку живого мониторинга: состояние служб, доступность источников и результаты проверяются отдельно.

## Закрытие инцидентов

Успешная повторная загрузка того же документа не доказывает исправление расширения. `COMPLETED`, `NO_CHANGE`, пустой список новых различий и строка сопоставления `NO_ACTION` не закрывают инциденты API-изменения, устаревшей операции или неоднозначного сопоставления. Их исходные ссылки на проблему сохраняются до отдельной приёмки совместимости и исправления; этот модуль не создаёт обход операторского одобрения.

Автоматически закрываются только проблемы самой проверки: `WATCH_RUN_FAILED` после завершённой проверки и `SOURCE_AUTHORITY_BLOCKED` после принятого снимка именно соответствующего источника в завершённой проверке. Частичное покрытие не выдаётся за восстановление.
