Что меняется

Не ещё один кабинет. Связка между вами, ИИ и API маркетплейса.

01

Работаете в привычном ИИ

Octoport не заставляет переносить работу в отдельную командную консоль. Основной интерфейс остаётся вашим диалогом с ИИ.

02

Явный запуск действий

Расширение исполняет подготовленные команды только после запуска пользователем. Текущую работу можно завершить явно.

03

Read-only на старте

Первая версия сфокусирована на чтении данных, формировании и скачивании отчётов — без редактирования бизнес-состояния кабинета.

Данные вашего магазина

Разбирайте данные Ozon и Wildberries в выбранном вами ИИ.

Для задач аналитики Octoport передаёт выбранному вами ИИ только разрешённые данные и отчёты вашего собственного магазина. Это не внешняя конкурентная аналитика и не автоматическое изменение состояния кабинета.
