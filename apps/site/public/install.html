Установка и API-ключи Октопорта

Сначала установите расширение из официального каталога браузера, затем добавьте в Октопорт ключи доступа своего магазина. Ключи вводятся в расширение — не в чат с нейросетью.

Официальные карточки расширения готовятся

Пока публичных ссылок на каталоги нет. Не устанавливайте случайные ZIP-сборки и не передавайте API-ключи третьим лицам. Когда карточки станут доступны, ссылки появятся здесь.

Шаг 2

Как получить API-ключи магазина

Для первой беты используйте доступ только на чтение. Названия пунктов в кабинетах маркетплейсов могут меняться — ориентируйтесь на разделы API/интеграций и проверяйте выбранный уровень доступа перед созданием ключа.

Ozon Seller API

Client ID + API key

  1. Откройте кабинет Ozon Seller и перейдите в Настройки → Seller API.
  2. Скопируйте Client ID.
  3. Нажмите «Сгенерировать ключ» и выберите роль Admin read only.
  4. Сохраните API key: секретный ключ показывается при создании, не отправляйте его в чат.
  5. В Октопорте откройте «Магазины» → Ozon и вставьте Client ID и API key в карточку Seller API.

Ozon Performance API

Для рекламной аналитики

  1. Performance-доступ нужен отдельно, если вы хотите разбирать рекламные кампании и расходы.
  2. Создайте API-клиент в кабинете Ozon Performance и получите его credentials.
  3. В Октопорте добавьте их в отдельную Performance-секцию того же магазина.
  4. Если Performance-доступ не добавлен, Seller API продолжает работать для остальных доступных данных.

Не выдавайте права на изменение кампаний: Октопорт в первой версии использует рекламные данные только для чтения и анализа.

Wildberries

Personal token · Только чтение

  1. В WB Partners откройте раздел Интеграции по API и создайте Personal token для своего магазина.
  2. Выберите только нужные категории данных. Для аналитики начните с «Аналитика»; «Статистика» и «Продвижение» добавляйте, если нужны соответствующие отчёты и реклама.
  3. Установите уровень доступа «Только чтение».
  4. Скопируйте токен и вставьте его в карточку Wildberries в Октопорте.

Как ввести ключи в Октопорт

  1. Откройте расширение и раздел магазинов.
  2. Выберите Ozon или Wildberries и создайте карточку магазина.
  3. Вставьте реквизиты в соответствующие поля и сохраните.
  4. Проверьте подключение. После успешной проверки вернитесь в диалог с нейросетью и нажмите «Начать».

Не вставляйте API-ключи в сообщения нейросети. Они предназначены только для формы подключения внутри расширения.
