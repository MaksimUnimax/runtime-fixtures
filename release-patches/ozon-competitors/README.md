```sh
git apply --check "$PATCH"
git apply --index "$PATCH"
git write-tree
```

Пути 02 и 03 восстанавливают полное дерево `d4ab3d3b5d9bd512f7f4ac7712e7dff23e2a196f`. Путь 01 содержит изменения платформы. Историческая проверка на данных магазина и манифест релиза доступны владельцу в ZIP.

В этой редакции исправлены сверка квитанций при удалении владельца, обработка STOP после истечения сессии, сохранность уже полученных фактов, изоляция ошибок кампании, CSV и фотографий, отображение полноты, проверка назначения и выбор исследования в чате. Постоянные сценарии находятся в `products/harness-platform/acceptance/competitor_invariants`.

В закреплённой среде из каталога `products/harness-platform` выполните `python -m unittest discover -s tests -p 'test*competitor*.py' -v`. Полные исходники, снимки испытаний, матрица, финансовая сверка и порядок ручной проверки переданы владельцу в комплекте для приёмки.
