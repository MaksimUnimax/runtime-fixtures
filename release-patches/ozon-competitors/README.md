# Анализ конкурентов Ozon — передача исходного кода

Проверенная сборка Октопорта — `b814094ad93cc949befd5bdef82325e84d5e0b04`. Эта ветка предназначена для ревью и содержит два альтернативных пути применения кода. Для каждого пути нужен свой исходный коммит. Используйте только один патч.

| Исходная версия | Файл | Область |
|---|---|---|
| Релиз `0deecb2089b4f56b28e21c7cf8e494fb4a8e3770` | `01-plugin-from-production.patch` | Оба режима, общий интерфейс, маршрутизация чата, сбор данных, права, биллинг, миграция и тесты. Файл повторения исторических данных магазина и общий манифест релиза входят в полный комплект владельца. |
| Отклонённый кандидат `5877dab263f83a3355c8bf0ebd9cf6b1058a8e39` | `02-system-review-from-5877dab.patch` | Полная разница до проверенного дерева, включая манифест и исправления S01–S07. |

Сохраните абсолютный путь к нужному патчу, откройте отдельное чистое рабочее дерево соответствующей версии и выполните:

```sh
git apply --check "$PATCH"
git apply --index "$PATCH"
```

Для второго пути результат `git write-tree` должен совпасть с деревом проверенного кандидата, указанным в `CHECKSUMS`. В комплекте владельца также есть клонируемый Git bundle, все исходники, отчёт и матрица по 60 критериям. Живой сценарий AC30 с пятью–десятью подтверждёнными конкурентами остаётся открытым. Выпуск требует отдельного решения владельца.
