Сохраните абсолютный путь к нужному патчу, откройте отдельное чистое рабочее дерево соответствующей версии и выполните:

```sh
git apply --check "$PATCH"
git apply --index "$PATCH"
```

Для второго пути результат `git write-tree` должен совпасть с деревом проверенного кандидата, указанным в `CHECKSUMS`. В комплекте владельца также есть клонируемый Git bundle, все исходники, отчёт и матрица по 60 критериям. В этой редакции основной тип и назначение из последующих частей названия проверяются по самостоятельным подтверждениям в описании. Нулевая индивидуальная оценка в отзыве сохраняется как неизвестная. Старый заказ с пометкой о некорректных строках можно бесплатно перечитать по исходной квитанции. Результаты живых исследований передаются владельцу в комплекте приёмки. Выпуск требует отдельного решения владельца.
