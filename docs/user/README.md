# Инструкции пользователя

Это целевые инструкции для будущей беты. На этапе D0 установочных пакетов Seller Agents ещё нет.
Статусы браузеров и ИИ перед приглашением беты публикуются по фактической приёмке.

## Начало работы

1. Зарегистрироваться, если набор открыт; существующий аккаунт может войти даже при закрытом наборе.
2. Установить принятый пакет своего браузера. Целевой сценарий D-39 — получить в кабинете email OTP-привязанный код аккаунта и ввести его в расширение; сохранённый код можно использовать в другом браузере без нового посещения сайта. Эта механика ещё не подтверждена в принятом пакете.
3. В popup выбрать Ozon или WB, добавить магазин и проверить ключи. Для Ozon обычный и рекламный API заполняются в одной карточке.
4. Открыть поддерживаемый ИИ самостоятельно, выбрать диалог и нажать «Начать работу».
5. Попросить нужную информацию. Один блок из нескольких явных команд запускается одним нажатием; команды выполняются последовательно.
6. Результаты поступают в тот же диалог. Для окончания нажать «Завершить».

ИИ использует ваш собственный аккаунт/подписку. Ключи магазина не передаются модели.
Сервис читает разрешённые данные; качество рассуждений ИИ и доступность данных площадки — разные вещи.

## Несколько магазинов

Можно работать с разными магазинами в разных диалогах параллельно. Имена магазинов редактируются.
Чтобы сменить магазин в том же диалоге, используйте явную смену и новый Start. Старая история останется; ИИ может смешать источники.
Движение переключателя popup само не перенаправляет уже запущенную команду.
Скрытие кнопки не завершает работу; Finish прекращает её будущие действия.

## Код подключения и ключи в другом браузере

В целевом сценарии код подключения привязан к аккаунту и вводится прямо в расширение; один сохранённый код можно использовать в другом браузере без обязательного посещения сайта. Публичный ID аккаунта не заменяет секретный код. Механика утверждена и поручена к немедленной реализации; пока она не принята в конкретном пакете, не считайте её доступной.

Подключение браузера не переносит ключи магазинов. Их получение новой установкой требует отдельного подтверждения владельца. Точный способ подтверждения фиксируется в техническом контракте реализации. Альтернатива — импорт единого защищённого файла. Аккаунт сервиса не является резервной копией локальных ключей.

## Ошибки

- Подтверждённо истёкший токен: обновить его в карточке магазина.
- Недостаточно прав: проверить права соответствующего API, не менять ключи наугад.
- Лимит API: результат указывает операцию и известную задержку; скрытого повторного запроса нет.
- Не доставлен файл: смотреть причину в popup; уже полученный результат можно использовать в пределах технического срока без нового запроса, если состояние доставки допускает это.
- Сервер временно недоступен: ранее разрешённая локальная работа продолжается в пределах допуска; новая активация требует связи.
- Закрытая регистрация: это лимит набора новых участников, а не запрет входа существующим.

Технический буфер результата доступен до одного часа; это не архив документов. Всё, что нужно сохранить надолго, сохраняйте в используемом ИИ или своими средствами.
Не отправляйте поддержке токены, пароли, полный диалог или отчёты магазина. Начните с кода ошибки, версии расширения, браузера/ОС/ИИ.
