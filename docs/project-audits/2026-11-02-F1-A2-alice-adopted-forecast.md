## 5. Дальнейшие семь и сравнение стратегии

Семь квалифицированных патчей не равны семи переключениям флага. Для каждого: сохранённый адаптер/contract → новый необходимый profile/code → full source → package/channel при code change → весь применимый технический и 45+8 смысловой scope на обеих площадках → активные потребители/изоляция → выпуск и наблюдение. Data-only допускается только внутри реально поддержанного packaged контракта; новые DOM/исполняемые возможности требуют клиентского обновления.
