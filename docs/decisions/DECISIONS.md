# Реестр принятых решений

Дата: 2026-09-16. Основание: последовательные решения владельца в проектном диалоге.
Это текущие решения; предложения из старых черновиков, противоречащие им, не действуют.

| ID | Принято | Что заменяет / следствие |
|---|---|---|
| D-01 | Один репозиторий и одно расширение Ozon/WB | Общий код сопровождается один раз |
| D-02 | Popup: Ozon слева, WB справа; выбор перерисовывает формы | Выбор не меняет реквизиты уже запущенного пакета |
| D-03 | Несколько магазинов, редактируемые названия | Название не идентификатор кабинета |
| D-04 | Ozon Seller и Performance внутри карточки магазина | Недоступная рекламная часть не блокирует доступный Seller |
| D-05 | Смена магазина в диалоге разрешена с предупреждением, новым Start и промптом | Заменяет пожизненную неизменность привязки |
| D-06 | Можно начать в существующем диалоге с историей | Старые команды не выполняются автоматически |
| D-07 | Ответвление — новый диалог; другой аккаунт ИИ имеет свои диалоги | Контекст и приватные чаты между аккаунтами не переносим |
| D-08 | Один клик запускает все явные независимые команды одного блока последовательно | Заменяет один клик на каждый envelope |
| D-09 | Клиентская авторабота удаляется; в разработке допустима временно | Автоматическая доставка уже запущенного пакета сохраняется |
| D-10 | Start, Show/Hide, Finish и явная смена магазина | Отдельных Pause/Stop в пользовательском интерфейсе нет |
| D-11 | Finish прерывает работу и будущие действия пакета | Новый запуск только с Start/промптом |
| D-12 | Результаты сразу в ИИ; технический локальный буфер один час | Нет отчётного архива, облака, произвольных имён/истории |
| D-13 | Магазины удаляются; архива нет | Служебная отметка удаления возможна для корректного согласования |
| D-14 | Авторизация беты обязательна, сама бета бесплатна | Первоначальные цены 199/299 не являются текущими обязательствами |
| D-15 | Учёт установок без коммерческого ограничения их числа | Лимит регистраций — другая механика |
| D-16 | Администратор открывает ограниченное число новых регистраций и увеличивает квоту | Новое требование: например 100, затем ещё 100 |
| D-17 | Ключи локальны и разделены по аккаунтам Seller Agents | При выходе: удалить или оставить для возвращения |
| D-18 | Перенос ключей через сервер только по согласию в принимающем браузере | В исходном браузере отдельного подтверждения нет |
| D-19 | Ключи постоянно на сервере не сохраняются; источник должен быть доступен | Если источника нет — открыть исходную установку или импортировать файл |
| D-20 | Один экспорт для всех магазинов текущего аккаунта | Сессии входа и буфер в экспорт не включаются |
| D-21 | В одной установке один исполнитель на диалог | Реализуется локально |
| D-22 | Между установками допускается временная параллельная работа | Заменяет строгую серверную lease на каждую команду |
| D-23 | Согласование по инициативе расширений, с сохранённой задачей и фоновыми повторами | Сервер не опрашивает браузеры постоянно |
| D-24 | При сверке учитываем последнюю известную доставку той же привязки | Поздний отчёт не отменяет смену магазина или Finish |
| D-25 | Ноль обязательных серверных запросов на обычный пакет/доставку | Редкая синхронизация не блокирует основную работу |
| D-26 | Лимиты API общие локально; между браузерами сервер не координирует | При 429 сообщается факт и отдельно вероятная причина |
| D-27 | Бета: Chrome, Opera, Yandex, Firefox. Safari/macOS сохранён как архитектурная возможность; работа вероятно после релиза | [Решение владельца 2026-09-23](../product/readiness/SAFARI_AFTER_RELEASE_2026-09-23.md): DEFERRED_POST_RELEASE_BY_OWNER, не блокирует бету, не означает Safari PASS |
| D-28 | Автоопределение ИИ; открытие ИИ через расширение не требуется | На странице нет дополнительной панели магазина |
| D-29 | Позиционирование «ИИ-сотрудник» | LLM пользователя; обещания ограничены реально доступными API |
| D-30 | Сервер хранит учётные сведения о магазинах и безопасную статистику | Не получает сырые отчёты/контекст/ключи обычными путями |
| D-31 | DOM Health и API watcher → специалист → кандидат → проверки → выпуск | Не автоматический production patch |
| D-32 | Препрод и рабочая бета разделены | Бесплатная бета с клиентами является production-средой |
| D-33 | Минимальный сайт до беты; детальные воронки позже | Коммерческие договоры/монетизация отдельно после MVP |
| D-34 | WB 0.3.0 INSTALLED FAIL; migration REOPENED; R1–R8 закрыты | Последняя owner-проверка сильнее старого READY_FOR_OWNER в Git |
| D-35 | D0 сейчас; перенос и объединение отдельными шагами архитектора | После переноса отдельный Codex дописывает сервер параллельно |
| D-36 | Общую интеграцию проверяем рано и по частям | Не ждём завершения всего старого серверного roadmap |
| D-37 | Зрелый Ozon — основной эталон применимой общей механики расширения; WB сохраняет специфику своего API | Уточнение владельца не меняет текущую последовательность D2. Существование старого общего WB кода или его зелёные тесты не доказывают эквивалентность; новые продуктовые решения имеют приоритет над старым Ozon поведением |
| D-38 | Будущая production-доменная authority переносится с `selleragents.ru` на `octoport.ru`: публичный сайт `octoport.ru`, портал `app.octoport.ru`, админка same-origin `app.octoport.ru/admin/`, API `api.octoport.ru`; `admin.octoport.ru` первоначально не используется как отдельный origin | Заменяет будущую production-топологию из ingress-плана 2026-09-09; работающий `docs.selleragents.ru` сохраняется до отдельной миграции; сначала завершаем доменную подготовку, затем начинаем новый публичный сайт |

Технические уточнения и открытые внешние проверки: [OPEN_ITEMS](OPEN_ITEMS.md).
Изменение решения: добавить объяснение замены, обновить нормативный документ и проверку. Не стирать исторические результаты и не задним числом объявлять тест принятым.
