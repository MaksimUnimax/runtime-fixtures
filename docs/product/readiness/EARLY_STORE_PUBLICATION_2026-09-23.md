# Решение владельца: ранняя магазинная публикация — приоритет

Дата: 2026-09-23. Владелец поручил при каждом контроле вместе с ресурсами оценивать готовность к публикации, подавать минимально готовую версию сразу и параллельно продолжать разработку. Аккаунты во всех выбранных магазинах, кроме Safari, зарегистрированы по его подтверждению; повторная регистрационная задача закрыта. Доступность Submit/проверки конкретного кабинета фиксируется при фактической подаче, без запроса повторной регистрации.

Указание «как только минимальные требования к публикации будут достигнуты сразу публикуем» является разрешением на раннюю подачу и публикацию соответствующей требованиям ограниченной версии в выбранных магазинах, последующие исправления и повторные подачи в том же объёме. Повторное абстрактное разрешение на Submit/Publish не требуется. Перед действием сохраняются конкретные package/version/hash, канал, честная карточка, результаты проверок и существующие ограничения доступа. Отдельный доступ/OTP запрашивается только если действительно нужен. Это не открывает автоматически общий набор пользователей, не меняет лимиты беты и не разрешает несогласованные production/migration изменения.

Safari исключён из беты по [предыдущему решению](SAFARI_AFTER_RELEASE_2026-09-23.md). Требования полного продукта сохраняются, но не объявляются все обязательными для первого узкого магазинного выпуска. Постоянный порядок: [STORE_POLICY.md](../../development/coordination/STORE_POLICY.md).

## Снимок готовности при закреплении правила

Проверено 2026-09-23, около 13:32 UTC; это снимок, при следующем контроле обновляется по фактам.

- Общая main: 3d217a8a902b334308410aaf5be949815f0c50bd. A: 0755f7c, исправление legacy-импорта подготовлено и подано C; B: e8a722a, retention исправление подготовлено и подано C. Оба требуют интеграции/проверки итогового пакета, не являются готовым магазинным релизом.
- C сообщает открытое согласование конкурирующей записи в своих четырёх health/no-session файлах и OpenAPI drift на a5fd724; состояние сохранено, не объявлено исправленным этой документацией.
- Firefox: проверенный development carrier, lint 0 errors, temporary install; source receipt A03_FIREFOX155_PRIVACY_MANIFEST. Это не окончательный store package или AMO-публикация. Итоговый reviewer flow и точный пакет первой подачи не подтверждены проверенными receipts.
- HEAD-проверки https://octoport.ru/ = 200; /privacy, /support, /install = 404. Альтернативные опубликованные страницы не установлены. Нужные магазинному сценарию страницы и карточка требуют подготовки независимо от полного SEO-сайта.
- Chrome, Firefox, Opera: BLOCKED для фактического Submit — требуется точный выпускаемый срез/пакет, проверяемый основной сценарий и reviewer flow, privacy/карточка/действующие нужные ссылки. Регистрация OWNER_CONFIRMED_REGISTERED. Yandex — проверка пути через каталог, не отдельная подача. Safari — DEFERRED_POST_RELEASE_BY_OWNER. Готовность дополнительного Edge отдельно не подтверждена; это не блокер остальных.
- Ресурсы: 15988 МиБ RAM, доступно 13505 МиБ, swap 0, memory PSI 0, OOM за последний час не найден; свободно 28033 МиБ диска и 3780274 inode. По этому замеру дополнительная ОЗУ сейчас не снимает публикационные блокеры; численный прирост от покупки не обещается. Ничего не удалено/остановлено.

Следующие действия: C выделяет ближайший минимальный store-кандидат и конкретные зависимости; A подтверждает выбранный браузер/основной сценарий, B — используемый backend/trust. Контроллер берёт независимые малые недоделки после проверки владельца пути. Все три потока продолжают разрешённую работу; существующие запросы контроля остаются открыты.
