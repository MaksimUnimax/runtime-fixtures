# Решение владельца: бета без Safari

Дата: 2026-09-23. Прямое указание владельца: «сафари после релиза скорее всего будем делать, бета без сафари».

## Действующее решение

- Safari / App Store не входят в первоначальную бесплатную бету Octoport и не блокируют её STORE-1…STORE-4, C06/C07.
- Возможная реализация Safari переносится на период после релиза. Это предварительное направление без обещанной даты и без автоматического запуска разработки/оплаты Apple.
- Архитектурная возможность Safari/macOS сохраняется. Реальное тестирование и публикация этого канала остаются отдельной будущей приёмкой. Текущий статус: DEFERRED_POST_RELEASE_BY_OWNER, не PASS.
- Владелец сейчас не должен предоставлять Mac/Safari или регистрировать/оплачивать Apple Developer. O19, O28 и Q1C-SAFARI-32 отложены; повторно запрашивать эти действия для беты нельзя.
- Требования к Chrome, Opera, Yandex и Firefox сохраняются. Отсутствие Safari не сокращает их проверки и не меняет 45 × 2 × 3 бизнес-сценария.
- В карточках первой беты Safari не перечисляется как поддержанный браузер. Неподтверждённые исторические результаты не переименовываются в принятые.

## Путь Opera → Яндекс Браузер

Яндекс официально поддерживает установку совместимых расширений из Opera Add-ons и Chrome Web Store. Публикация в Chrome не является обязательным условием пути Opera → Yandex. После принятия пакета Opera пользователь открывает его карточку из Яндекс Браузера и устанавливает оттуда; отдельный Yandex publisher account для этого пути не нужен.

Это доступный канал распространения, а не доказательство совместимости нашего пакета. A/C отдельно проверяют обычную установку, активацию, функциональность и обновление N → N+1 из Opera в Яндексе. Проверяются также фактические package ID, trust/origins и сохранность пользовательских данных; равенство идентичностей разных каталогов не предполагается. Модерация Opera остаётся отдельным условием. Отказ Chrome по безопасности/приватности требует исправления причины; смена магазина её не устраняет.

Источники, проверены 2026-09-23: [Яндекс](https://yandex.com/support/browser/ru/personalization/extension), [Opera](https://help.opera.com/en/extensions/publishing-guidelines/).
