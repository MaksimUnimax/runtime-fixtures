# Popup и пользовательские действия

Целевая спецификация. Наличие экранов в этой документации не означает их реализацию.

## Основной экран

Сверху: аккаунт Seller Agents и состояние подключения. Затем двухпозиционный переключатель: Ozon слева, WB справа, с видимой подписью выбранного положения, управлением клавиатурой и различием не только по цвету.
Ниже: список магазинов выбранной площадки, кнопка «Добавить магазин», редактирование названия и проверка ключей. Основной статус: «Диалог не подключён», «Работаем: …», «Завершено» либо конкретная проблема.
Основные действия: «Начать работу», «Показать/скрыть кнопку», «Завершить», «Сменить магазин или площадку». Недоступные действия объясняют причину.

Переключатель перерисовывает доступные формы сразу. Во время активной сессии это выбор следующего магазина: отдельно остаётся ясная строка текущего подключения. Само движение переключателя не меняет исполнителя и не отправляет промпт.
При возвращении к popup отображается текущая привязка активного диалога, а не последний выбор из другой вкладки. Черновик создания магазина не должен попадать в чужой аккаунт.

Макет проектируется в устойчивой ширине popup с проверкой реального viewport каждого браузера и масштабирования. Перенос mature Ozon включает функциональную структуру, зависимости, состояния и действия. Совпадение цвета или число строк CSS не доказывает полноту.

## Карточка магазина

| Поле/действие | Поведение |
|---|---|
| Имя | По умолчанию «Ozon 1», «WB 1» и далее; редактируется без смены идентичности |
| Ozon Seller | Client ID и API key, отдельная проверка состояния |
| Ozon Performance | Реквизиты актуальной схемы API, отдельная проверка; отсутствие не мешает Seller |
| WB | Токен и подтверждённая область прав; ограничения показываются по фактам API |
| Секрет | Скрыт по умолчанию; вставка разрешена; не попадает в диагностику/телеметрию |
| Проверить | Пользовательский запуск проверки доступности, идентичности и прав |
| Удалить | Подтверждение с перечнем затронутых локальных сессий; без архивирования |

Тексты проверки: «Ключ действителен» только после подходящей проверки; «Срок токена истёк — обновите токен» только при достоверном expiry; «Недостаточно прав для …», «Не удалось проверить: сеть/площадка недоступна», «Кабинет не подтверждён».
Один 401 сам по себе не доказывает истечение. Срок, прочитанный из непроверенного содержимого токена, помечается как заявленный до подтверждения.

## Диалог

| Ситуация | Действие интерфейса |
|---|---|
| Поддерживаемый ИИ, диалог без привязки | Выбор площадки и магазина; Start отправляет промпт, после подтверждения отправки закрепляет текущий диалог. Предварительный адрес/ID не требуется |
| Диалог имеет историю | Разрешён Start; baseline отсеивает уже существовавшие команды |
| Уже подключён тот же магазин | Показать состояние и подключиться к известной привязке, без ненужного нового промпта |
| Другой магазин уже привязан | Показать его имя; предложить явную смену с предупреждением |
| Ответвление | Новая идентичность диалога, отдельный Start |
| Неподдерживаемая страница/ИИ | Понятное объяснение; команды и токены в страницу не отправлять |
| Локальное подключение есть, сервер временно недоступен | Показывать автономное состояние и ожидающее согласование, сохраняя допустимую работу |

Предупреждение смены: «В диалоге останутся данные предыдущего магазина. ИИ может смешать их в ответах. Для нового подключения нажмите “Начать работу”; будет отправлена новая инструкция».
Если выполняется пакет, смена сначала завершает старую локальную сессию по правилам Finish. Поздний ответ старого магазина не доставляется под новой привязкой.
Дополнительную панель магазина на странице ИИ не создаём. Состояние достаточно показывать в popup и в метаданных результата.

## Кнопки и жизненный цикл

Start создаёт намерение запуска для текущей страницы, отправляет стартовый промпт один раз и затем закрепляет подтверждённый диалог. Это одна последовательность для всех ИИ и любых типов диалога; новый адрес после первого сообщения уточняет ту же привязку. В уже активной той же сессии повторный клик идемпотентен. См. [полный жизненный цикл](../architecture/CONVERSATION_BINDING_LIFECYCLE.md).
Кнопка рядом с выбранным блоком разрешает весь блок. Повторный клик занятого/завершённого executionId не дублирует сетевой запрос.
Show/Hide скрывает только кнопку, не отменяет уже разрешённый пакет. Finish завершает работу, убирает кнопку и останавливает наблюдение DOM.
Закрытие popup не равно Finish. Перезагрузка страницы восстанавливает только допустимое состояние; не означает повторного API-запроса.

## Перенос и резервная копия

«Перенести магазины» показывается после входа в новый браузер. Получатель выбирает доступную исходную установку и подтверждает передачу через сервер. В исходном браузере дополнительного подтверждения нет.
Текст при недоступном источнике:
«Мы не храним ваши ключи. Для переноса откройте браузер с расширением, где сохранены магазины, и войдите в тот же аккаунт Seller Agents. Либо импортируйте сохранённый файл ключей».
Статус ожидания не должен обещать мгновенный ответ: расширение может быть приостановлено браузером.

Экспорт создаёт один защищённый паролем файл для всех магазинов текущего аккаунта. Пароль не отправляется серверу. При импорте показать список без секретов, конфликты и явные варианты «добавить»/«обновить выбранный».
Не перезаписывать другой кабинет по совпадению имени. Ошибка формата сообщает поддерживаемые варианты; не обвиняет пользователя без проверки файла.
Импорт не запускает работу и не переносит исполнительную привязку.

При выходе: «Оставить ключи на этом устройстве для следующего входа?» с вариантами оставить/удалить. Данные другого аккаунта недоступны до возврата к нему.
Подробные сообщения ошибок не содержат ключей, полного ответа площадки или содержимого чужого диалога.
