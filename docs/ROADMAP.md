## Немедленный приоритет — решение владельца 2026-10-27, 12:08 UTC+5

Механика аккаунтного кода подключения имеет статус APPROVED_REQUIREMENTS / IN_PROGRESS: владелец поручил её немедленную реализацию существующему Тестеру с максимальным приоритетом; фактический результат реализации ещё не проверен и не принят. Тестер не ждёт обычной очереди; после проверенного завершения работы возвращается к ранее назначенным блокам. Работа не откладывается до B02/B06. Эта реализационная очередь не меняет порядок продуктовой приёмки B01–B33. Детальные технические поля и схема остаются ответственностью Тестера в существующем контракте.

Кандидат R5 сохранён, продуктовая ветка и мониторинг объединены с прежним main. Это база разработки, не production-релиз.
Release blockers, браузерные ограничения и live-проверки остаются открытыми по единому плану. Сайт/SEO вне этой программы.
