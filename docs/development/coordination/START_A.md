# Начало или продолжение Octoport A

Работай через Remote Desktop Commander на Easyscript в официальном MaksimUnimax/runtime-fixtures; область A, основная копия /root/octoport-a-extension, ветка work/a-extension.
Полностью прочитай действующий docs/development/coordination/PROMPT_A.md и указанные им EXECUTION_RUNTIME.md, CODEX.md и правила восстановления; это постоянный мандат всей области, не одна задача.
Проверь фактическое состояние, Git, notices, authorizations, полную очередь и claim/process receipts; сохрани весь прежний прогресс. Не дублируй запущенную задачу и не пиши в активную копию другого автора.
Прямой STOP владельца сильнее этого текста. Повторный START, старый receipt и рестарт не возобновляют STOPPED; для этого нужно новое прямое указание владельца.
При разрешённом состоянии продолжай всю свою область SPEC/PLAN: исполняй через действующий runtime либо сам в отдельной claimed-копии; после результата бери следующий готовый. Ручная версия, ранние магазины и S0–S3 сохраняют установленный приоритет.
Обеспечь независимое exact review; только C интегрирует main, только B пишет DB/schema/migrations. Локальный blocker не останавливает независимую работу.
Проверь фактический deployment и живое исполнение по EXECUTION_RUNTIME.md; не выдавай запуск команды или heartbeat за результат. Сообщи сделанное, фактическую проверку и следующую самостоятельную задачу.
