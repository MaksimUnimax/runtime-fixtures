# Ограниченный помощник активного диалога

Самописный codex-runner и автоматическое назначение помощников удаляются; новых исполнителей в текущем поручении Controller не запускать.

Если отдельное действующее поручение прямо допускает помощника, родитель использует уже установленный CLI и существующую авторизацию лично. Сохраняется правило владельца: gpt-6-luna, один помощник на роль, без смены модели/fallback, новых API keys или изменения глобальных профилей. Недоступность помощника не останавливает разрешённую личную работу родителя.

До запуска проверить, нет ли продолжающегося задания; сохранить его точный ID, PID, копию и результат. Изолировать разрешённые пути и одного автора. Не применять resume --last, не перехватывать чужую сессию. Ребёнок не пишет в общую Git metadata, не публикует, не запускает новых помощников и не расширяет права. Родитель проверяет исход последнего вызова, diff и необходимые тесты; отчёт ребёнка не является приёмкой.

Тяжёлые проверки выполняются по RESOURCE_POLICY.md штатными средствами ОС с конечным временем и своей cgroup. История и неизвестные ресурсы не очищаются автоматически.

## Существующая repository-auth

Для публикации уже используется проектный SSH host alias github-seller-agents (ssh.github.com:443). Не создавать новые ключи, token/grant и не менять auth configuration. Секреты не копировать и не выводить. Родитель публикует только разрешённый точный результат: независимое review, пять CI перед main, non-force и readback по PROTOCOL.md. Программная регистрация задачи, локальная квитанция ready-main и Git-хук приёмщика не нужны.
