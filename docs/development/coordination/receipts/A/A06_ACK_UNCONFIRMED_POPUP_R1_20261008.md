# A06 — понятное сообщение при неподтверждённом ACK передачи

Дата: 08.10.2026. Задача: `A06-TRANSFER-ACK-UNCONFIRMED-POPUP-SAFE-TEXT-R1-20261008`.

## Основание

Утверждённый A06 требует понятной и безопасной диагностики. При восстановлении передачи A02 сохранённый локальный импорт может ожидать подтверждения ACK, а сервер — вернуть `TRANSFER_ACK_UNCONFIRMED`, `TRANSFER_REPLAY` либо непроверенный `TRANSFER_EXPIRED`. Прежний popup сообщал техническую ошибку или предлагал новый запрос до подтверждения терминального состояния. Это могло провоцировать повторный импорт.

## Изменяемая область

- `apps/extension/src/application/popup.js` — понятные тексты; показ ожидающего ACK только при `ackConfirmed === false`, состоянии `IMPORTED_PENDING_ACK` или `PENDING` и известной ошибке неопределённого подтверждения.
- `tests/regression/extension-core/client-i1/client-transfer-popup-ack-unconfirmed.mjs` — отдельная синтетическая проверка, не меняющая занятый A02 тест.
- Эта квитанция.

Статус `TRANSFER_ACCOUNT_MISMATCH` не превращается в успех, `TRANSFER_REQUEST_MISMATCH` не раскрывает частное содержимое. Только `ok:true / IMPORTED` разрешает прежний `consume`. Подтверждённый `EXPIRED` продолжает показываться как завершившийся запрос, а не ожидающий ACK.
