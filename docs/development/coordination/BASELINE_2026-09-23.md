## Незакрытое, что не маскируется объединением

1. R5 Opera: WORK_START_PENDING_COMMIT_READBACK_FAILED и account timeout требуют A01; прежний candidate не стал принятым.
2. Chrome/Yandex/Firefox/Safari требуют собственных доказательств по A03. Контролируемый health browser driver сейчас ограничен своими поддерживаемыми средами; общий enum из пяти семейств не доказывает пять драйверов.
3. Legacy B1 prepare/preflight выведены из использования: всегда BLOCKED_UNVERIFIED_RELEASE, exit 78, без записи пакета. Это fail-closed quarantine, не завершение C01. Положительного валидатора выпуска пока нет.
4. Bootstrap catalogs, перенос после MV3 restart, bounded relay, semantic API diff, service hardening и реальный recovery включены в [план](PLAN.md) с владельцами и критериями.
5. Git hooks локальны и отключаемы пользователем с доступом к серверу; GitHub main не становится защищённой веткой автоматически. OS sandbox между чатами не создан. Серверный RDC имеет широкие права.
6. Product release/live migration/deployment требуют отдельных проверок и разрешений. Сайт/SEO остаются отдельной работой.
