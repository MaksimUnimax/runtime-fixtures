# Общая доставка результата и продолжение roadmap

Действующий полный метод — WORK_METHOD.md, точные команды — PROTOCOL.md, ручная выдача — OPERATOR_TESTING_POLICY.md.
Этот документ сохраняет прежнюю ссылку и не вводит второй порядок. Личные компонентные очереди A/B/C и постоянные C-only-main/B-only-DB отменены. У общей задачи один автор, конкретные paths, критерий и evidence; он ведёт весь результат.
Готовый проверенный пакет сохраняется отдельно от развивающегося main. Автор сразу продолжает roadmap; OPERATOR выдаёт пакет по запросу, контроллер может выдать при аудите. Замечания остаются в общем operator/feedback и связаны с одной технической задачей.
Legacy tasks/evidence не считаются вновь принятыми. При восстановлении сверить существующий код, exact SHA и ограничения прежде чем заказать повторную реализацию. Незавершённое нельзя закрыть заменой статуса.
Никакой server executor/scheduler не добавлен. Исполнители — обычные чаты через MCP и прежний механизм повторения управляющего промпта. RUNNING/heartbeat не доказывают активную работу.
Каждый аудит отдельно проверяет причинную цепочку ночного простоя и замечание→пакет, а не только готовность частных модулей. База организационных ошибок сохраняет историю и доказательство эффекта.
