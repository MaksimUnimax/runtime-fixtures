# Публикация без организационного приёмщика

Действующие правила: [WORK_METHOD.md](WORK_METHOD.md) и [PROTOCOL.md](PROTOCOL.md). task_publication, обязательные registration/completion-bundle/queue-card и автоматическая приёмка результата выведены из порядка работы прямым указанием владельца 11.10.2026. Новый аналог не создавать.

Исторические регистрации и квитанции остаются доказательствами. Их наличие или состояние не заменяет проверку кода, тестов и результата. Закрытые результаты не повторять; незавершённые не объявлять DONE по смене правил.

Публикация сохраняет одного автора, разрешённые пути, независимое review, точный SHA, пять обязательных CI перед main, non-force Git и readback. Защита GitHub, авторизация, SOURCE-before-write и адресные ограничения не меняются.
