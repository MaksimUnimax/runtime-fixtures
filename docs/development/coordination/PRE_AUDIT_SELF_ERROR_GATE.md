# Ручная самопроверка контроллера

По указанию владельца 11.10.2026 организация ведётся инструкциями и промптами. Этот файл — памятка. Программный gate, PASS_TO_AUDIT, отдельная разрешающая квитанция и очередь аудита не требуются.

Перед возобновлением прочитай текущие рабочие документы задачи, checkpoint и относящиеся к ним первичные результаты. При неизменных правилах используй уже проверенный контекст; повторно сверяй изменившиеся положения и новые первичные evidence.

Проверь собственные действия:
- ORG-006: доступное исправление выполнено лично и проверено на исходной границе; план и независимая работа не закрывают обязательный исход.
- ORG-007: утверждения об инструментах соответствуют фактическим вызовам. Частичный discovery не доказывает отсутствия функции. Исторический отказ не является общей текущей недоступностью. Явный отказ конкретного действия не обходить.
- ORG-009: до вывода выбрать необходимые поля. Большие данные сохранить в имеющемся audit scope; наружу выводить ограниченную проекцию менее 6000 символов.
- ORG-038: при полном аудите сопоставить факты по всем запрошенным ролям с текущими рабочими документами задачи, checkpoint и первичными результатами. Для непроверенного указать NOT_RECHECKED; полноту и исправление не объявлять по наличию документа.

Перед сообщением сопоставь каждое утверждение с результатом: запуск не равен завершению, запись требует readback, уведомление не равно исполнению, тест источника не равен live. Если источник не изменился, повторное полное чтение этой памятки перед каждым сообщением не требуется. Фактическая проверка утверждений требуется всегда.

Собственную ошибку сохраняй в существующем рабочем документе задачи или checkpoint с первичным evidence, без двойного учёта одного случая. Новый программный контролёр, сервис, база или реестр для этой памятки запрещён.
