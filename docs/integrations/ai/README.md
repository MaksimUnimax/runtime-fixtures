# AI adapters и совместимость

Начальные цели: ChatGPT и Алиса, их явно поддерживаемые surfaces/variants. Новые ИИ появляются как отдельные адаптеры и отдельная приёмка.

## Порт адаптера

detectTarget, identifyConversation, observeEligibleCommandBlocks, resolveComposer,
insertPrompt/result, attachFile, requestSend, proveSendOutcome, recoverObservation.
Это роли порта, не предписанные имена функций, отсутствующих в текущей реализации.
Нужны capabilities: text/file, поддерживаемые MIME/size budgets, доступные способы подтверждения отправки, account/conversation scope.

Команда ищется в правильном сообщении ассистента и в текущем диалоге после baseline. Заголовки, Copy/Edit, цитаты и содержимое чужой вкладки не являются командным payload.
Исчезнувший текст composer, вызванный click и worker ACK сами по себе не доказывают успешную доставку. Нужен новый соответствующий user-turn либо иной принятый target-specific proof.
UNKNOWN отделён от подтверждённого no-send и success; recovery наблюдает, не кликает Send заново скрыто.
Пользовательский непустой draft не затирается молча. Смена account/route/composer проверяется после await.

## Промпт

Общий протокол одного блока команд, текущая площадка/магазин, HELP, ограничения доступа и последовательность явных действий.
Каталог реальных операций, HELP и проверка команд остаются общими. Дерево подсказок и ответов выбирается отдельно для ИИ по его постоянному ID; публикация, signed config sync и границы версии описаны в [Per-AI hint and answer trees](../../architecture/SYNC.md#per-ai-hint-and-answer-trees). Содержимое подсказок и их логика пока не задаются.
Большие ответы не подталкивают ИИ угадывать потерянные строки.
Стартовый промпт не содержит ключей. При смене магазина явно сообщает новую область и предупреждает о старых данных в истории.
Промпт помогает слабому ИИ, но не служит единственной защитой формы и разрешённых операций — это проверяет код.

## Серверные профили

Профиль выбирает встроенные возможности и ограниченные параметры. Новая DOM-логика, которой нет в установленной сборке, требует обновления пакета.
Не считать серверную админку универсальным удалённым исправлением любого DOM. Граница packaged code соответствует [правилам Chrome о remote hosted code](https://developer.chrome.com/docs/extensions/develop/migrate/remote-hosted-code).
Health сигнал различает drift, реальный отказ и отсутствие наблюдения. Автоматическое отключение всех клиентов по одной CAPTCHA запрещено.
Процесс наблюдения: [MONITORING](../../operations/MONITORING.md).
