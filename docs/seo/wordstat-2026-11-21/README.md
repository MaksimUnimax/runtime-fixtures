## Как назвать продукт

«ИИ-сотрудник» описывает делегирование работы. Для поиска рядом с ним стоит проверить выражение **«ИИ-агент для маркетплейсов»**. У «ии для маркетплейсов» широкая цифра включает карточки, изображения и другие задачи. Отдельную широкую категорию нельзя целиком приписать спросу на универсального сотрудника. Запрос «менеджер маркетплейсов» приводит к вакансиям и обучению, что видно по его вложенным фразам. «Создание карточек для маркетплейсов» также смешивает продавцов с исполнителями, которые ищут работу. ## Как использовать ядро

1. **О сервисе.** Проверить в выдаче «ии агент для маркетплейсов» и «ии для маркетплейсов». Собрать на одной странице реальные обязанности, текущие функции и примеры будущих поручений с указанием их статуса.
2. **Аналитика продавца.** На существующей странице показать задачу владельца действующего магазина. Запросы на анализ ниш, конкурентов и поиск ассортимента требуют другой базы данных. Для финансовых отчётов, расчёта прибыли и падения продаж проверить востребованность отдельных пошаговых разборов.
3. **Карточки.** Развести в выдаче инструмент для фотографии или инфографики, оформление карточки внутри кабинета и отправку готовых данных на площадку. Принятый плагин иллюстраций позволяет показать конкретный пример. Утверждение об автоматической публикации требует сквозной приёмки записи.
4. **Реклама.** Инструкцию по ДРР и разбору расходов можно строить на чтении данных. Запрос «биддер» предполагает выполнение операций со ставками. Перед коммерческой страницей проверить требования к типам кампаний и готовность функции.
5. **Контроль и уведомления.** Постоянные поручения важны для продуктового отличия. Спрос по прямым фразам про бота и сигналы слабее или неоднозначен. Пока показать этот сценарий в описании продукта с его статусом. Решение об отдельной странице принять после проверки выдачи.
6. **Смежные инструменты.** «Калькулятор прибыли озон» и «репрайсер озон» имеют измеримый спрос. Первый предполагает работающий калькулятор экономики товара, второй — настройку и выполнение правил переоценки. Монеты Octoport и статистика цен не закрывают эти ожидания.

## Как повторить измерение

Исходный инструмент — Wordstat Bridge reference 1.1.5, адаптированный для отдельного запуска на сервере. Широкий запрос передавался в getTop без операторов. Для исходных запросов передавали numPhrases от 80 до 120, для проверки в кавычках от 1 до 3. Параметры всех вызовов — регион 225, DEVICE_ALL. Период обзора динамики — полные месяцы с апреля по сентябрь 2026, PERIOD_MONTHLY. Один проход с более точным оператором и проверка ассоциаций отделили общие рубрики от задач продавца. Ключи доступа и сведения об аккаунте в выгрузку не входят.

**Граница данных.** Яндекс сообщает, что в API недоступна статистика после 7 октября 2026 года. getTop не возвращает календарные границы окна. Снимок от 21 ноября нельзя выдавать за частотность ноября или за календарный октябрь. История в отдельном файле использует явно указанные месяцы. [Доступность данных и метод getTop](https://aistudio.yandex.ru/ru/docs/search-api/operations/wordstat-gettop)

**Метрики.** Широкая частотность — totalCount отдельного запроса либо count этой формулировки в results исходного запроса. Источник указан в строке. Для кавычек берётся исключительно totalCount отдельного запроса в кавычках. Значения в results этого ответа могут быть шире. Кавычки фиксируют число слов, но допускают варианты словоформ и порядка. При совпадении морфологии или перестановке слов измерения могут пересекаться. Частотности не суммируются, не переводятся в уникальных пользователей, клики или прогноз трафика. Пустое поле означает отсутствие числового значения или измерения согласно столбцу состояния. [Операторы Wordstat](https://yandex.ru/support2/wordstat/ru/content/operators)

**Полнота.** Собрано 2 725 уникальных строк после приведения регистра и пробелов. Вложенные фразы и ассоциации сохранены раздельными полями. По 1 040 проверенным в кавычках формулировкам получено числовое значение. В рабочем ядре 493, на проверке 656, исключено 1574, брендовых 2. В ядро брали только вручную отобранные формулировки с подтверждённым положительным значением в кавычках, каждой назначили одну тему. Широкие запросы без фразовой цифры остались видны в реестре. Брендовое написание «Октопорт» и латинское Octoport выделены отдельно. Снимок охватывает выбранные задачи и варианты расширения. Данные выдачи, позиции сайта и конверсия требуют самостоятельной проверки.

**Динамика.** По широкому «ии для карточек маркетплейсов» Яндекс вернул 2 070 в апреле и 2 074 в сентябре. Значения за остальные месяцы есть в выгрузке. Наличие такого спроса подтверждается несколькими отдельными месяцами. Для части более редких запросов API прислал даты без count.
