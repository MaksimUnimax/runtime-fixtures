14 ноября 2026. **UI/BFF/Django/PostgreSQL проверены в изолированном окружении. В рабочую Алису не установлено.** Это продолжение backend-коммита1507cfeccc1f3ff5909e028079785d96c84b21aa, не замена текущего ядра.

## Законченный участок

Страница `/app/parameters` читает список определений и текущее значение из существующего owner_data. Доступны ручной ввод процента/рублей, ноль, общие параметры, SKU-исключения по подтверждённому товару, возврат к общему, дата последнего расчёта, свежесть источников и статистический период. Предыдущее число и его паспорт не архивируются. Форма себестоимости не заменена: добавлена закрытая флагом ссылка.

Новый BFF использует прежнюю сессию, service-token, Origin/Host и строгий JSON; URL не задаётся пользователем. Клиент не может записать произвольный calculated-result. Процент переводится в долю строковыми операциями, без потери точности двоичного float.

Потеря ответа после сохранения оставляет только metadata pending-команды в localStorage. Повторное открытие проверяет статус, а не повторяет изменение. Статус старой команды отдаёт текущее число и отмечает superseded, не возвращая старое значение из receipt. Если браузер не может надёжно сохранить metadata перед командой, запись не отправляется. Номера, предыдущие числа, даты сборок и credentials в localStorage не хранятся.

Режим подготовки расчёта показывает год по умолчанию, полгода/три месяца/свои даты и preview/replace. Неизменённый год передаётся как default, а не строго заданные12месяцев: это сохраняет возможность подтверждённой короткой истории. Реальный сбор пока не подключён, поэтому кнопка называется «Проверить период и доступность сбора» и возвращает `PARAMETER_SOURCE_NOT_QUALIFIED`, `dispatched=false`. Она не имитирует успешный расчёт и не пишет число. Окончательная кнопка запуска появляется только с квалифицированным producer/job-путём.

## Дополнительные проверки ядра параметров

Проверяется, что фактический период входит в запрошенный, explicit не сокращён, short_history согласован с диапазоном, as_of не раньше конца фактического периода. Несовместимая единица существующего параметра блокирует применение, не вызывает скрытый refresh. Сервер отдаёт своё время для ограниченного допуска команды; обычная давняя открытая форма не требует дат от пользователя и не перезаписывает конкурентное изменение.

## Что ещё не завершено

1. Квалифицированные исторические источники заказов/исходов/доставки и исполнитель двух producer-template через действующий job. Текущие scalar/dataset названия не доказывают совпадение годовой когорты.
2. Голосовые мутации. В прочитанном установленном `alice_link/oauth.py` scope=`reports:read`. `AlicePrincipal` проверяет именно его. Нельзя просто принять этот bearer в owner-data write как разрешение менять настройки. Нужен явно авторизованный mutation-intent, связанный с существующим владельцем и текущими правами. Новая привязка/новые OAuth scope не объявляются обязательными без отдельного анализа. OAuth/доступы/рабочие связи в этом патче не изменялись.
3. Согласованный current-revision fence до выдачи расчёта и очистка transient job-паспортов, не превращающихся в историю.
4. Слияние с актуальной параллельной платформой и миграциями, точная toolchain, рабочая установка и физическая голосовая приёмка.
