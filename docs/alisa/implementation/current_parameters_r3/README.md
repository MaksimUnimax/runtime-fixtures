## Реальный прирост

Добавлены два декларативных producer-рецепта: потери физических заказанных единиц и средняя прямая+последняя доставка. Источники и финансовые группы описаны в parameter_producers.json; общий код не ветвится по имени коэффициента и не содержит значений993/7761или101,61.

parameter_producers.py: нормализация квалифицированных выгрузок, полный охват FBO/FBS/периода, контроль окончания пагинации, объединение физических возвратов без двойного счёта отмены, отдельные pending, знаковые расходы и явно перечисленные статьи. Незнакомые статусы/размерности, пропуски, неподтверждённые source-receipts, возврат больше заказа и пересекающиеся финансовые интервалы запрещают результат. Неизвестное не становится нулём.
