## Что фактически сделано

В рабочем контейнере написан отдельный пакет v0.5 с внешней JSON-матрицей, нормализатором, строгим JSON-контрактом модели, SQLite-очередью, точным кэшем, проверками claim/lease, ограниченным HTTP-адаптером, декодерами Ozon/WB, обработкой ответов Decimal, readback/refresh/cancel и совместимым фасадом для существующего вебхука.

Новый процесс исполнения отделён от web-процесса локальным Unix-сокетом. Сокет проверяет UID вызывающего процесса; web-процесс передаёт уже установленный OAuth-кодом tenant, текст и идентификатор запроса, но не ключи и не access token. Worker предназначен для отдельного непривилегированного пользователя, собственного state directory и systemd LoadCredential. Пример unit не установлен и не активирован.

Список файлов исходников: registry.json, registry.py, semantics.py, repository.py, providers.py, engine.py, http_transport.py, local_gateway.py, alice_bridge.py, runtime.py. Также в пакете конфигурация-пример, пример unit, корпус, генератор корпуса, три тестовых файла, run_checks.py, логи, README, ARCHITECTURE, INTEGRATION_STATUS и MANIFEST.

**Содержимое ZIP не опубликовано целиком в Git и не установлено на Alisa.** Эта запись — контекст и указатель на проверенный пакет, а не утверждение о наличии всех исходников в ветке.

## Объём матрицы

Реализованы для кандидата: ordered_units и ordered_revenue, Ozon/WB/обе площадки, один полный период, группировка по площадкам либо общий итог при совместимой подтверждённой валюте. Месяц не разбивается на дневные запросы. Ozon получает только выбранные совместимые метрики одним payload; WB получает полный период с offset-пагинацией.

ДРР, расходы на рекламу, выкупы, прибыль, остатки, фильтры SKU/бренд/склад, сравнения и конвертация валют не реализованы. Для них возвращается адресный отказ, без подмены заказами. Это незавершённая часть общей продуктовой матрицы, не скрытая рабочая возможность.

Календарь кандидата фиксирован в Europe/Moscow; фактические даты входят в план и ответ. Источник не объявляется RUB при неизвестной валюте. Межмагазинное суммирование денег запрещено при неизвестных/разных валютах.

## Проверенные инварианты

Полный канонический ключ включает аккаунт, ревизии доступа/источников, снимок постоянных магазинов, даты/timezone, показатели, группировку, валюты, определение и хеш матрицы. Изменение матрицы инвалидирует не только ключ результата, но и старое подтверждение квалификации декодера.

Кэш только READY + complete + authorized + nonexpired по точному ключу. Нет overlap, склейки недель, извлечения подмножеств показателей/магазинов или усреднения процентов. Промежуточные страницы принадлежат только текущему заданию. UNKNOWN не повторяется автоматически, включая refresh. Повтор результата не вызывает модель или площадку.

Состав «все магазины» фиксируется при приёме, в том числе до P2; добавленный позднее магазин не попадает в старое задание. Отзыв доступа закрывает чтение сохранённого результата. Один кабинет не считается дважды. Отдельный тест использует 25 синтетических магазинов; это не нагрузочная гарантия произвольного масштаба.

Состояния: QUEUED/RUNNING/READY/FAILED/UNKNOWN/CANCELLED/ALIASED. Отмена и истечение lease запрещают поздний commit. Запись READY дополнительно сверяет речевую проекцию с нормализованными данными. 401/403 блокируют только затронутый источник; 429 сохраняет cooldown; неизвестный сетевой исход остаётся UNKNOWN. Частичная сумма не озвучивается как полный итог.
