# Октопорт маркет · единая работа тестера и автора матрицы

**Начинать каждый рабочий сеанс здесь.** Репозиторий `MaksimUnimax/runtime-fixtures`, ветка `alisa`, каталог `docs/alisa/quality/`. Переписка и ZIP — передача материалов, не второй реестр задач.

## Куда смотреть и куда писать

| Задача | Постоянное место |
|---|---|
| Что уже есть, что открыто и что брать следующим | [BOARD.md](BOARD.md), генерируется из JSON |
| Дефекты, ограничения и предотвращённые ошибки | [BUGS.json](BUGS.json) — единый реестр с прежними ID |
| Кандидаты шаблонов и зависимости | [TEMPLATES.json](TEMPLATES.json) |
| Исторические протоколы проверок | [RUNS.json](RUNS.json) |
| Новый материал тестера | `inbox/<UTC-дата>-<роль>-<уникальный-ID>/`, формы в [forms](forms/) |
| Порядок проверки, исправления и выпуска | [WORKFLOW.md](WORKFLOW.md) |
| Постоянный стартовый промпт агенту | [TESTER_PROMPT.md](TESTER_PROMPT.md) |
| Что именно перенесено из архива | [IMPORT_MANIFEST.json](IMPORT_MANIFEST.json) |
| Проверка целостности реестров | `python3 tools/qa_check.py --check`; после изменений `--render` |

Тестер пишет новые отчёты в отдельную папку inbox; автор ядра после triage обновляет реестры и BOARD. Это исключает одновременную перезапись одной огромной таблицы двумя агентами. Повторный дефект ссылается на прежний ID, новый ID не создаётся ради каждой фразы. Последующие исправления исходного отчёта — отдельное дополнение с причиной, не переписывание первоначального FAIL в PASS.

**Исходники не потеряны.** Приложенный архив содержит 19 исходных файлов: 5 CASE, 7 журналов, 7 исследовательских Python-файлов. Все контрольные суммы проверены. Старые CASE и журналы остаются на прежних путях и закреплены commit/SHA; в новом реестре они — исторический источник, не ещё одна активная очередь. 27 записей — это не 27 подтверждённых багов рабочего сервиса.

## Роли

Тестер — сценарии, независимый ожидаемый результат, воспроизведение, измерения, кандидаты, повторная проверка. Автор ядра — матрица/исполнитель, triage, регрессии, интеграция и пакет для повторной проверки. Платформенный исполнитель — UI/BFF, issuer/authority, adapter, платформенные роли и публикация через админку. Владелец утверждает продуктовые решения и необходимые активации. Тестер не пишет в рабочую БД и не публикует каталог сам; автор ядра не закрывает дефект словом «исправил» без нужной повторной проверки.

## Первая очередь

1. **RT-CAT-R01**: безопасное чтение/запуск опубликованного неизменяемого шаблона через уже написанный RuntimePort; тесты на версии/отзыв/слоты/права. Выполнен offline-срез: 846/846 проверок ядра, 46 новых; не production публикация. Контракт в `../runtime/v0.11/rt_cat_r01/README.md`.
2. **SRC-OZON-ACCRUAL**: один декларативный источник начислений с signed-строками, line-vs-unit, полным курсором и осью начисления. Под него связаны OZCP-002/004/005 и OZYOY-001/007. Это следующий функциональный источник, не пять отдельных обработчиков.
3. Цены реализации и дневные количества/средняя — первые кандидаты поверх этого источника; затем явная повторная проверка Алисы на тестовом выпуске.
4. Способы оплаты — только после общего источника метаданных и квалифицированного соединения; неизвестная метка не равна «без карты».
5. Сравнение лет — отдельно заказная и начисленная оси, равные завершённые даты и московские границы. Исследовательские пороги цены — после общего статистического оператора и независимого gold; не причинный вывод.

Очередь — решение triage автора ядра, не переименование статусов исходного тестера. Подтверждённая утечка/неверная денежная арифметика имеет приоритет над FIFO; причина переупорядочивания записывается.

## Текущие ограничения

Все пять импортированных кандидатов **не установлены**. Исследовательская квалификация не подтверждает текущий build и не равна чеку/кабинетной сверке. Новые реальные запросы при импорте не выполнялись. Включать их по новому словарю синонимов без источника/формулы нельзя. Сырые ответы по старым закрытым путям могут уже исчезнуть по TTL; это не повод обещать, что они существуют, или повторять платный/неопределённый запрос вслепую.
