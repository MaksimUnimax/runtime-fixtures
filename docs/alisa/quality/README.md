## Роли и безопасность

Тестер — сценарии, независимый числовой эталон, воспроизведение, измерения, кандидаты и retest. Автор ядра — матрица/исполнитель, регрессии, общие примитивы и собственные release-пакеты. Платформенный исполнитель — UI/BFF, issuer/authority, adapter, PostgreSQL и административная публикация. Владелец — продуктовые решения и необходимые активации.

Тестер не меняет working SQLite/config/ключи/права. Полные реальные денежные ответы — в одобренное закрытое evidence, в Git очищенные тексты и refs/hashes. Полный Request Алисы с access_token не публиковать; для N06 достаточно очищенных command/original_utterance. Source HTTP200 не заменяет корректность цифр, а runtime smoke не заменяет внешний Яндекс. Неизвестный исход не повторяется вслепую; история отказов по TOOL_FAILURE_RUNBOOK.
