## Действия владельца перед следующим шагом

Сначала сохранить для себя неотправленную сумму, затем Ctrl+F5 на https://alisa.octoport.ru/app/owner-inputs. Выбрать «Кровь и Песок», указать обе реальные даты и сумму общей себестоимости, подтвердить и сохранить. Ожидается версияN>0, строки сохраняются после «Обновить версию». Некорректное поле должно выделиться и получить фокус. При потерянном ответе — «Проверить сохранение», не новая правка. Пароли/коды/ключи не запрашивать.

**Следующий шаг — принять повтор сохранения пользователя.** Пока не расширять задачу на новые функции и не считать его параметры уже подтверждёнными.
