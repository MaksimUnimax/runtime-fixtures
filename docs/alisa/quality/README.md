## Архитектура и границы

Общий TaskGraphRuntime использует существующие Engine, Worker и Repository. Стадии и курсоры находятся в `jobs.progress`, квоты — в одном `calls/rates`; второго планировщика, HTTP-клиента и бюджета нет. Exact-only кеш допускает только полностью готовый идентичный результат при текущих правах и TTL.

Граф, проекции, зависимости, лимиты и формулы задаются матрицей. Доверенные расчётные адаптеры закреплены по версии. Пользовательская фраза не задаёт исполняемый код или произвольный API. Отсутствующие значения не заменяются нулями, частичный результат не становится READY, UNKNOWN не повторяется автоматически.

Себестоимость 250 ₽, исключённый налог и неуказанные собственные расходы относятся только к утверждённому примеру r9. Это не настройки по умолчанию для магазинов. Производственное owner binding, голосовой маршрут и доставка результата через умный дом не считаются готовыми.
