### Граница готовности

**C-UE01 ещё не в производственной очереди Worker и не в голосовом навыке.** Завершён реальный квалификационный source-to-scenario запуск отдельного кандидата. Нет универсального production issuer/task/voice adapter; callbacks проверяют конкретный авторизованный bundle и текущую конфигурацию. Две реальные таблицы не означают готовый endpoint. Нужны durable task/pin, cancel/restart/replay/TTL, права на execution/read и отдельный exact release. Parent/split/full-lifecycle случаи за пределами этой простой as-of выборки не объявлены закрытыми.
