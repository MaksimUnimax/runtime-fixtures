### Защищённые ответы и файлы

Полные чувствительные JSON и binary выдаются владельцу через peer-checked внутренний gateway. В очереди — AES-GCM ciphertext; в модели — непрозрачные reference и безопасные метаданные. При чтении повторно проверяются tenant/store/job/current rights и конкретная беседа. Чужая или отменённая беседа, отзыв доступа, expiry и tampering запрещают выдачу.

Signed URL принимается только из явного поля успешного report API того же магазина. Fixed provider-domain policy, HTTPS, без credentials/редиректов; API-ключи на файловый сервер не передаются. CSV/XLSX читаются без выполнения формул/внешних XML и без скрытого float/date inference. Неизвестный binary не выдаётся за прочитанную таблицу.

Payload TTL≤900секунд; действующий retention timer удаляет истёкший ciphertext и обслуживает WAL. Недельная метрика вызовов модели сохраняет собственный срок. **Публичный экран скачивания и полная физическая голосовая приёмка документов здесь не реализованы/не заявлены:** проверена серверная выдача через защищённый шлюз.
