# Общая пауза после HTTP429 —20секунд

Изменена общая функция request_recovery.retry_due: для любого безопасно повторяемого запроса со статусом429 собственная пауза составляет20секунд при каждом повторе. Правило одинаково для Ozon, Wildberries и модельных вызовов; формулировка пользовательского вопроса и IDшаблона не участвуют.

Больший Retry-After от площадки и существующий интервал метода сохраняют приоритет. Поведение остальных временных ошибок не меняется. Сохраняются одно задание, общий cooldown источника, отмена, проверка доступа и журнал реальных попыток. Шаблоны, промпты и голосовые сценарии не меняются.

База установки: alisa-template-only-r2-s07-acl-r2-20261109. Модуль взят из фактически установленной базы, включая template_select/template_verify; новые файлы накладываются на всю текущую базу.
