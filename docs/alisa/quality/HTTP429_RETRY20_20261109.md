# Общая пауза после HTTP 429 — 20 секунд

Изменена общая функция request_recovery.retry_due: для любого безопасно повторяемого запроса со статусом 429 собственная пауза составляет 20 секунд при каждом повторе. Правило одинаково для Ozon, Wildberries и модельных вызовов; формулировка пользовательского вопроса и ID шаблона не участвуют.

Больший Retry-After от площадки и существующий интервал метода сохраняют приоритет. Поведение остальных временных ошибок не меняется. Сохраняются одно задание, общий cooldown источника, отмена, проверка доступа и журнал реальных попыток. Шаблоны, промпты и голосовые сценарии не меняются.

База установки: alisa-template-only-r2-s07-acl-r2-20261109. Модуль взят из фактически установленной базы, включая template_select/template_verify; новые файлы накладываются на всю текущую базу.

Установлено: alisa-retry20-r1-20261109, исходный commit fd4a0f350afe63dadba077a1163519c017ef40f3. Полная установленная база сохранена; файлы без изменений используют то же дисковое хранение. Изменяются только request_recovery.py и его тесты. Пройдены 25 проверок восстановления, независимое ревью APPROVE. Реальные запросы на колонку при этой правке не запускались.
