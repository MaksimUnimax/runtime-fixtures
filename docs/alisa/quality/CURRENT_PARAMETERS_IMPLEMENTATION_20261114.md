# Сохраняемые коэффициенты: первый серверный блок

14 ноября 2026. **Реализован и проверен изолированный backend; не установлен в рабочий сервис.**

Владелец отменил предложение хранить историю значений коэффициентов. Текущее правило: одно число и паспорт последней сборки на магазин/параметр/область. Чтение даты не запускает сбор. Заполненное значение не меняется без прямой команды; первичное вычисление допустимо при отсутствии.

## Сделано

Добавлены CurrentParameter и миграция внутри существующего owner_data; уникальность текущей записи, Decimal-контракт, общие периоды/формулы, read/manual/inherit и внутренняя атомарная запись рассчитанного значения. Метаданные идемпотентности не сохраняют старые числа. Повтор старой команды выдаёт текущие данные, не восстанавливает удалённое значение. Конкурентная запись проверяет техническую ревизию.

Дата сборки коэффициента calculated_at, дата исходных наблюдений collected_at, дата ручного изменения/записи updated_at различаются. Ручная замена полностью очищает прежний расчётный паспорт. SKU имеет собственное значение либо наследует общее; отсутствие исключения не копирует общий коэффициент в сотни строк.

Производитель описывается декларативно; запись требует независимого подтверждения исходных данных доверенным адаптером. Значения993/7761и791884,33/7793 не импортировались в БД и не встроены в код исполнения — только синтетические регрессионные примеры.

## Проверено

77/77 новых тестов на PostgreSQL16.15 (контейнер network=none) PASS, включая реальные конкурентные соединения, историю/даты, ноль, ручную замену, ошибку/конфликт, права и tenant/SKU-изоляцию. 18/18 прежних тестов каталога товаров PASS. Внешних сетевых попыток0; платных модельных/API-вызовов0. Новая миграция применялась только к одноразовой тестовой БД. Полная регрессия всего ядра и независимыйreview NOT_RUN.

Существующие данные себестоимости, службы и актуальный runtime основного агента не изменялись. Тесты не использовали реальные токены/данные магазина.

## Исходники и граница подключения

Локальный кодовый коммит `1507cfeccc1f3ff5909e028079785d96c84b21aa`, базовая платформа `81579c18d4725c7f0a6603c8abbf703668863e36`. Код сохранён в собственной ветке `feat/alisa-current-parameters-code-20261114` на Easyscript. Git-публикация ветки из shell недоступна без учётных данных; источник и git format-patch входят в передаваемый комплект, а не выдаются за уже объединённые в main.

Код касается owner_data/config-additions/tests, не рабочего template-runtime. При объединении особенно сохранить параллельные AL-S11 изменения config/settings.py и config/urls.py. Нельзя переносить целиком старую платформенную сборку поверх новой.

Осталось подключить: квалифицированные исторические producer-рецепты и verifier; текущую runtime/voice-authority для подтверждённой записи; форму ЛК; голосовой выбор операций чтения даты/ручной установки/пересчёта; fence текущей ревизии перед выдачей отчёта; очистку временного payload завершённой сборки. Наличие backend API само по себе не означает, что колонка уже меняет коэффициент.
