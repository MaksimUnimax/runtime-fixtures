# Квалификация полей и границ даты

Ozon FBO: created_at; цена products[].price.amount/currency. В проверенном FBS v4 ответа created_at нет, присутствует in_process_at. Начало обработки не объявляется физической сдачей и не переименовывается без проверки в точную дату создания исходного заказа. Для приёмки C-UE01 исполнитель должен проверить фильтр/API axis и заказы возле полуночи, сверив с order analytics; поле и зависимость записаны в Ozon JSON. Это источник-зависимая квалификация, не доказанный новый баг runtime.

WB: полная order-feed выборка фильтруется по createdAt; selectedPeriod выбирает время текущего статуса. Сохранять snapshotTime. Предварительный supplier/orders не заменяет ленту при расхождении. Поля тарифа: FBW paidStorageKgvp, FBS kgvpMarketplace; kgvpSupplier не использовать вместо FBW. Это кандидат, требующий независимой приёмки на точной реализации.
