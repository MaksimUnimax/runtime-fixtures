# Подборка аналитических шаблонов

Это навигация по ранее собранным спецификациям и новому кандидату по дате заказа. Документы сами по себе не включают сценарий в голосовой навык. Исторические пять записей общего реестра имеют TRIAGED и runtime_enabled=false; готовность рабочих scalar/dataset сценариев ведётся отдельно в quality/README и не переписывается этим индексом.

| Шаблон | Временная ось и назначение | Документ |
|---|---|---|
| Юнитэкономика Ozon, C-UE01 | Заказы выбранной даты; два сценария, расходы, среднее на физическую единицу, доля статьи от цены продавца | [Ozon UE](OZON_ORDER_UNIT_ECONOMICS.md) |
| Юнитэкономика Wildberries | Заказы/операции WB, расходы и возвраты с квалифицированным охватом | [WB UE](WB_ORDER_UNIT_ECONOMICS.md), [границы возвратов](WB_RETURN_SCOPE_CORRECTION.md) |
| **Цена реализации покупателя по дате заказа — новый** | Товары, заказанные в выбранную дату; цена из их начислений, включая более поздние | [Описание](OZON_CUSTOMER_PRICE_BY_ORDER_DATE.md), [JSON](OZON_CUSTOMER_PRICE_BY_ORDER_DATE.json) |
| Цена покупателя по товарам | Дата финансового начисления; построчные суммы и количество | [OZON_CUSTOMER_PRICES_CASE](../../../runtime/v0.10/candidates/OZON_CUSTOMER_PRICES_CASE.json) |
| Дневные количества и средняя цена реализации | Дата начисления, SKU × день, взвешенное среднее | [OZON_DAILY_PRICE_VOLUME_CASE](../../../runtime/v0.10/candidates/OZON_DAILY_PRICE_VOLUME_CASE.json) |
| Разбивка реализаций по способам оплаты | Подтверждённые метки оплаты, отдельная группа unknown | [OZON_PAYMENT_METHODS_CASE](../../../runtime/v0.10/candidates/OZON_PAYMENT_METHODS_CASE.json) |
| Ценовые диапазоны и пороги | Исследовательская связь ценовых диапазонов и объёма, без заявления причинности | [OZON_PRICE_BANDS_CASE](../../../runtime/v0.10/candidates/OZON_PRICE_BANDS_CASE.json) |
| Октябрь/ноябрь по дням, год к году | Заказы и начисления по раздельным осям, сопоставимые завершённые периоды | [OZON_YOY_SEASONALITY_CASE](../../../runtime/v0.10/candidates/OZON_YOY_SEASONALITY_CASE.json) |

Общий реестр кандидатов: [TEMPLATES.json](../../TEMPLATES.json). Новый шаблон не подменяет старый по дате начисления: это другой выбор исходных товаров.

Для статистики рекламных стратегий актуальные тарифы Ozon запрашиваются при каждом фактическом сборе. Ставка комиссии API, денежный эквайринг и расчётная доля расхода сохраняются раздельно, с датой получения. Никакие проценты из конкретного магазина не закрепляются в общих шаблонах как универсальные тарифы.
