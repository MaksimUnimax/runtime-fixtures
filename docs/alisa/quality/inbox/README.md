# Входящие материалы тестера

Новый сеанс: отдельная папка `<UTCYYYYMMDD>-TESTER-<8hex>/`. Внутри RUN_REPORT.json, один BUG_<ID>.md на наблюдение и TEMPLATE_<ID>.json на новый кандидат по формам `../forms/`. Добавления после проверки — новыми файлами, не перезаписью старого FAIL.

Перед созданием проверьте BUGS.json/TEMPLATES.json: существующий смысл сохраняет прежний ID. Новая папка нужна для воспроизводимого run, не для дублирующей очереди. Автор ядра после triage переносит ссылки/статус в канонические реестры и генерирует BOARD. Git-запись только после чтения актуального SHA; чужое изменение не перетирать.

Не сохранять токены, полный Request Алисы, персональные данные или сырые финансовые строки. Кандидат остаётся NEW/неисполняемым до спецификации, независимого gold, тестов и утверждённого release. Постоянный процесс: `../WORKFLOW.md`.
