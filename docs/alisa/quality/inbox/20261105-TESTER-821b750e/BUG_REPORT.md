## QA-20261105-TESTER-821b750e-JOIN · RESEARCH_FIX / CAPABILITY_GAP
Получены свежие by-day, справочник типов и начисления по выбранным отправлениям. У всех выбранных отправлений posting_accruals пусты; при этом by-day содержит item_fees по order_number и SKU. Найденные фактические денежные суммы имеют приоритет над текущими тарифными оценками; отсутствующие суммы не превращаются в нули.

## Не закрытые источником ограничения
- FBO cancellation detail не показывает достоверную стадию передачи. Не назначать ни обязательную полную обратную логистику, ни обязательный ноль.
- Отдельные услуги ПВЗ/упаковки/хранения возврата и состав return_flow должны быть квалифицированы до объявления полного результата. Не добавлять складскую обработку повторно.
- CPO refund для обычных отмен/возвратов и сроки остаются неподтверждёнными в доступном официальном тексте; сохраняются реальные списания, корректировки требуют основания.
- Стоимость заказов и фактически признанная выручка различаются. Не подменять исходные ordered units числом реализаций финансового дня.
- В прогнозе рекламные расходы и хранение всего магазина распределены по когорте явно; это не точное отнесение каждого рубля к отправлению.
- Консервативно сохранённая тарифная оценка эквайринга отмен не является доказательством реального удержания; фактическое сторно меняет итог.

## Предотвращённые ошибки
Не использовать старые денежные ответы; не выводить ставку эквайринга из суммы; не придумывать комиссию отмен; не смешивать переменные финансовые расходы другого набора отправлений с новой тарифной моделью; сохранять причину каждого незаполненного компонента и обозначать X вместо мнимого полного net profit.
