## OWNER ACCEPTANCE RULE — последняя команда имеет приоритет

Фиксированный знаменатель: все исходно заказанные единицы. Выручку отменённых заказов исключать. Себестоимость отменённых товаров исключать. Все фактически понесённые расходы Ozon и рекламы по отменённым сохранять; не делать автоматического уменьшения комиссии/логистики/рекламы. Реальные возвраты удержаний учитываются только по подтверждённому источнику.

Себестоимость и налог задаёт пользователь; если не указаны — доступны явные частичные показатели с пометкой исключённых статей. Обязательная реклама — другое правило: неизвестная/противоречивая реклама блокирует пригодную юнитэкономику. Налог текущим поручением исключён.

Это уточнение отменяет прежние варианты себестоимости по unrelated realized units и себестоимости всех ordered units без исключения cancellations. Ранее выданные headline unit-profit numbers отозваны как проверенная юнитэкономика выбранных заказов. Их арифметические базы менялись и не образуют один сопоставимый расчёт.
