Статус на 13.11.2026: **INSTALLED_TECHNICAL_CHECKS_PASS**. PR419,
product source `81579c18d4725c7f0a6603c8abbf703668863e36` установлен в кабинете,

Если зарегистрированный шаблон подходит, но не хватает периода, смысла
показателя или другого обязательного условия, модель задаёт один короткий
вопрос. Ответ продолжает тот же запрос. Новые шаблоны используют общий механизм;
перечня конкретных шаблонов и отдельного парсера бизнес-фраз нет. Если самого
шаблона нет, сохраняется прежний ответ о неподдерживаемом запросе.

## Поведение

- Планировщик возвращает закрытый вариант `plan`, `clarify` или `unsupported`.
- Уточнение вызывает только существующую модель выбора. API маркетплейса,
  итоговая модель и создание документа до ответа не запускаются.
- RuntimePort выдаёт NEEDS_INPUT с result_kind CLARIFICATION. Это вопрос,
  который нельзя представить как готовый бизнес-отчёт.
- Ответ сохраняет public query ID, native job, runtime ref, исходный вопрос,
  календарь, часовой пояс и исходный набор магазинов. Уточнения видны обеим
  существующим моделям отдельно от исходного вопроса.
- Каждый ответ требует актуальные права, revision вопроса и отдельный request ID.
  Устаревшая версия или изменённый ответ под прежним ID отклоняются.
- При потере уже принятого ответа разрешён явный повтор с теми же ID, revision
  и текстом. Он подтверждает прежнюю отправку без второго расчёта.
- Продолжение запрещено для разделяемого задания и после любого запроса к API.
  После последней проверки прав повторно проверяются TTL и execution ticket.
  Сохраняется короткий исходный TTL; максимум четыре уточнения.
- Кабинет показывает поле ответа в карточке задания. Неопределённая отправка
  сохраняется в открытой странице до явного повтора. Новый голосовой канал
  сохраняет контекст в зашифрованном VoiceDialogue; фраза «повтори отправку»
  повторяет исходную отправку. Другой диалог этот контекст не получает.
- Последний выбранный магазин остаётся значением по умолчанию для следующих
  запросов. Пока идёт уточнение, исходные магазины закреплены; для их изменения
  требуется завершить или отменить этот запрос.
- Обычный ответ и документы API продолжают сохраняться общим архиватором
  по шаблону на 48 часов. Уточняющий вопрос документом не становится.
