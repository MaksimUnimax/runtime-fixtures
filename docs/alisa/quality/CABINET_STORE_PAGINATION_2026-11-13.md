# AL-S09 — страницы магазинов в форме отчёта

Статус: SOURCE_IN_PROGRESS. Это продолжение установленного автоподключения
магазинов PR417, source `592cc8bb`, и ранее установленной формы PR415.

Форма задания получала только первые 50 карточек. Магазин за пределами этой
страницы нельзя было выбрать. Если первые 50 карточек отключены, форма предлагала
подключить новый магазин, хотя подходящий уже был на следующей странице.

Добавлена явная кнопка «Показать ещё магазины» через существующий авторизованный
BFF и подписанный cursor API списка. Каждое нажатие загружает одну страницу;
доступна и страница после пустой по подходящим магазинам части списка. Загруженные
карточки объединяются по ID. Текущий выбор и введённый вопрос сохраняются; новые
карточки не выбираются автоматически. «Выбрать все в списке» действует на уже
загруженные карточки. Незагруженные страницы не считаются выбранными.

Пока идёт загрузка, форма не отправляет отчёт. При ошибке HTTP, неверной структуре
страницы или повторении cursor список, вопрос и выбор сохраняются для явного
повтора. Состав уже отправленного UNKNOWN/recover задания остаётся прежним;
подгрузка и выбор до подтверждения отправки заблокированы. Чтение списка не
создаёт задание и не обращается к модели или маркетплейсу.

Добавочный browser fixture использует настоящие PostgreSQL, BFF и три страницы с
подписанными cursor. В первых 50 карточках нет подходящих; следующие страницы
содержат 55 активных подтверждённых карточек. Проверяются выбор магазина на
поздней странице, UNKNOWN и явный recover с тем же ID/вопросом/набором, запрет
подгрузки во время UNKNOWN, ошибки HTTP/структуры/cursor без сброса формы, перенос
выбора и текста через страницу и полный выбранный список из загруженных страниц.
Только POST создания отчёта перехватывается браузерным fixture; настоящего
исполнения этих многомагазинных расчётов он не доказывает.

Реальные расчёты и скачивание документов проверяются прежним отдельным сценарием
до добавления дополнительных fixture-карточек. Новый сценарий не заменяет эти
проверки и не меняет область исходного запроса. Все его карточки удаляются при
закрытии собственной одноразовой тестовой БД.

Изменение относится к web-компоненту: миграции, ключи, права, native и серверный
выбор последнего магазина не меняются. Полнота семантических уточнений S09 и
LIVE_OWNER остаются отдельной приёмкой. Установка этой доработки ещё не выполнена.
