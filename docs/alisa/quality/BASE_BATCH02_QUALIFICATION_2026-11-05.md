# BASE-BATCH-02 — реальные результаты перед включением

05.11.2026. Основание: BASE_BATCH_02_PLAN_2026-11-05.md, commit 7953c38e9b576b50be7d323bf300a915f6d64560. Active до этого этапа: base-batch01, собственный staged каталог `/opt/alice-market/releases/20261105-v010-base-batch02-r1`. Platform/issuer/adapter/UI/PostgreSQL не затрагиваются.

## Общее ядро, не обработчики отдельных фраз

SourceMatrix расширен общими ограниченными операциями flatten вложенных рядов, составной cursor_page и offset_empty; в конечном JSON-языке добавлены chunks/числовые CSV-ID/UTC-граница дня. Новый dataset_pipeline интерпретирует этапы, fanout, проекции и группировки из dataset_queries.json; его Python не содержит имён девяти API-рецептов или названий семи отчётов. Один этап использует прежний защищённый HTTPTransport/общий ledger, а не отдельный запросный клиент.

Разработаны 9 рецептов и 7 семейств (9 сочетаний с площадками): справочники Ozon/WB, цены Ozon/WB, метаданные отправлений Ozon FBO+FBS, выбранные рекламные кампании WB, начисления Ozon по товарам/дням/товарам-дням. Реализовано не равно квалифицировано и не равно установлено.

## Первый canary: 9 HTTP, шесть разобранных ответов

01:24:10–01:24:12 UTC. 7 HTTP200, 2 HTTP400. Квитанция `/var/lib/alice-market/dataset-batch02-canary-r1.json`. Выполнялись первые страницы, не обещание полноты отчёта.

Справочник/цены Ozon, первая страница цен/карточек WB, список кампаний WB и строки начислений Ozon успешно нормализованы. FBO/FBS дали 400: исходный кандидат ошибочно использовал limit=1000 и не задавал sort_dir. Перечитан сохранённый исследовательский контракт с limit=100/sort_dir=asc и translit=false для FBO; определения исправлены в JSON. Конкретное тело HTTP400 транспорт не сохраняет, поэтому единственный точный серверный diagnostic неизвестен. После изменения контрактов полный canary обоих методов вернул200.

Товарный price API Ozon фактически содержит marketing_seller_price, не старое marketing_price. Поле поправлено в матрице и названо маркетинговой ценой продавца, НЕ конечным чеком или ценой Ozon Карты. Product/list содержит product_id, offer_id, sku. Оба источника возвращали total и total_items; оба проверяются на согласованность, new-only форма покрыта тестом.

WB fullstats для первых 50 исторических eligible кампаний вернул HTTP200 с JSON null. Null не превращён в нули; source не принят.

Три отказа не являются неуспехом Ozon HTTP или доказательством неверной формулы.

## Допуск к следующему действию

Разрешён только ограниченный read-only rollout пяти PASS сценариев: source ops ds_ozon_products, ds_wb_products, ds_ozon_prices, ds_wb_prices, ds_ozon_fbo_postings, ds_ozon_fbs_postings. В config dataset_capabilities и qualifications включаются только эти шесть операций с точными source/query hashes. Девять написанных рецептов не означают девять разрешённых источников. Ads и новые dataset accrual проекции остаются выключены до отдельного допуска; старый scalar B05 сохраняется.

Перед переключением сверить own lock, active manifest, отсутствие пользовательских QUEUED/RUNNING/pending, source hashes и пять PASS. Приватная SQLite backup, атомарный config, отдельный drop-in, штатный restart только alice-market. OAuth/таймеры/платформа не меняются. В случае неуспеха вернуть прежний config/drop-in и запустить batch01 без восстановления БД поверх новых данных. После — фактический health и адресный gateway smoke; не объявлять production или независимую консольную приёмку.

Открыто: невыясненная полнота рекламной статистики, fresh full dataset B05 после освобождения квоты, qualified posting-to-accrual join, себестоимостьS03 и C-UE01. Справочник одной площадки не считается кроссплощадочным mapping; метаданные отправлений за период фильтра не считаются реализацией по дате начисления.
