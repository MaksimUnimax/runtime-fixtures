## Почему установка ещё не выполнена

Проверка существующего SSH-пути Easyscript → Alisa завершилась тайм-аутом. Был сформирован вызов подготовки зашифрованного файла через существующий HTTPS-сайт, без новой службы или порта.

AI-клиент дважды остановил одинаковый вызов до его отправки устройству. После этого неизменённый вызов передан штатному `review_device_call`. Карточка имеет статус **awaiting_user** и содержит кнопки **Run / Cancel**.

Заблокированная команда не выполнялась, не заменялась другим каналом, не дробилась и не запускалась обходным способом. Файл передачи не создан и не опубликован. Это не отказ владельца и не ошибка уже запущенной серверной команды. До подтверждения Run зависимая передача и установка не выполняются.
