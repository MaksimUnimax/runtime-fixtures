## Реализовано в отдельной копии

Два формата сборки `legacy_v1` и `catalog_prefix_v2`; старый формат по умолчанию сохраняется, новые задания получают зафиксированный сервером выбор. Стабильные поля каталога вынесены перед переменным контекстом. Изменяемые хеши/версии/время/магазины отсутствуют перед каталогом; метаданные хранятся отдельно. `purpose` участвует в выборе, `notes` и изменение версии только из-за notes не меняют selector-view.

Подготовленный запрос сохраняется для побайтового повторения при временном сбое/перезапуске. Cache miss не вызывает retry. Обычный вопрос сохраняет два модельных вызова. Права остаются проверяемыми сервером.

Добавлены server-owned `user_id` для необязательного режима `tenant_v1` и учёт этапа/layout/hash в прежнем недельном calls-ledger. A/B использует один и тот же профиль изоляции в обеих ветках. Кэширование ответов, Redis и новые фоновые службы не добавляются. Поддержка нескольких одновременно исполняемых версий каталога не включается в эту поставку.

42 новых адресных теста прошли; идёт полная локальная регрессия с запретом внешних соединений. Отдельно выполняется конечный selector-only A/B: фиксированные тестовые вопросы, без запросов Ozon/WB, без production-job и без колонки. Платные QA-вызовы учитываются отдельно; показатели не смешиваются с рабочей средней стоимостью вопроса.
