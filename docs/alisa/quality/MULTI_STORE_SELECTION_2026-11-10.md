## Проблема и изменение

Platform API уже принимает `store_ids` и проверяет каждый магазин через существующий authority. Кабинет отправлял только один ID из select, поэтому пользователь не мог явно ограничить вопрос несколькими магазинами.

В форме появляются отдельные флажки, «Выбрать все в списке», «Снять выбор» и число выбранных магазинов. Начальный выбор одного магазина сохраняется. При пустом выборе отправка недоступна. Набор берётся из текущих разрешённых карточек без списка площадок или шаблонов в коде формы. Существующий API отдаёт страницу из 50 карточек; если есть продолжение, форма явно предупреждает, что показана часть магазинов. «Все в списке» не обещает выбрать невидимые страницы. Полная навигация большого списка остаётся частью дальнейшего S09.

При отправке копируется и сортируется список IDs. В UNKNOWN сохраняются исходные ID запроса, вопрос и набор магазинов; флажки заблокированы. Только явная «Повторить ту же отправку» повторяет тот же состав и номер. Успешное подтверждение освобождает форму. Проверки владельца/ключей/доступа остаются серверными.

Это клиентская часть S09. Изменение не заявляет голосовой выбор/уточнения, полноценный диалог или доказанную полноту численного итога нескольких маркетплейсов. Выбор и проверка шаблонов остаются в текущем исполнителе. Новых миграций, привязок магазинов, прав или вызовов платных API в рабочей среде нет.
