# Маршрут расчёта программой установлен

Рабочая версия: **alisa-program-answer-r1-20261111**. Источник ядра: `282f29c2c533c5d1009fb4a46221325a989dceb4`, поверх фактически установленной `alisa-query-insights-r1-20261110`.

**Меньше 10000 символов исходного JSON — прежний прямой ответ модели. От 10000 — полный файл, программа модели, её выполнение официальным Harness и окончательный ответ модели.** Размер считается до упаковки, без токенизаторов и выделения сервером нужных полей. Выбранный маршрут и настройки ответа закрепляются за заданием перед первым итоговым вызовом. Шаблоны и API-данные не урезаются.

Отдельный изолированный исполнитель запускается через Unix-сокет ядра. Рабочая папка ограничена отдельным tmpfs 256 МиБ, поэтому запись файлов программой не заполняет диск хоста. Ключ DeepSeek остаётся в обычном транспорте ядра. Каждое внутреннее обращение, включая исправления и полученные ошибки, проходит существующие авторизацию, HTTP-отправку и семидневный журнал вызовов. Используется отдельная стадия `model_answer_program`, видимая существующему учёту по этапам. Кэш и reasoning учитываются через конечную usage провайдера, без повторного сложения.

Полученный 429 повторяет тот же payload по общему правилу 20 секунд либо большему Retry-After. Неизвестный сетевой исход не повторяется; известные полученные usage сохраняются и при неполном ответе. Отмена, потеря владельца или прекращение работы ядра останавливают исполнитель. Долгий расчёт продлевает только действующую аренду задания. Собственных квот по числу вызовов или выходным токенам нет; ограничения самого провайдера и защита ресурсов сервера сохраняются.

Файл, программа и локальная сессия удаляются после завершения/остановки. Неактивные аварийные каталоги старше часа убираются с проверкой каждые 15 минут. Текущие задания уборка не удаляет. Исполнитель видит свою рабочую папку и системные runtime-монтирования readonly, без ключей и файлов других заданий.

В существующий редактируемый **answer_prompt** добавлено:

> Кратко ответь только на вопрос пользователя. Оставь лишь запрошенные сведения. Не озвучивай ход вычислений, технические подробности и пути файлов. Не добавляй причины и объяснения, которых нет в полученных данных.

Требование писать все числа словами сохранено. Промпт выбора шаблона сохранён; третья переменная остаётся пустой. Сервер текст модели не переписывает и по ключевым словам не проверяет.

Проверки:

- Полный прогон ядра: **1951/1951**.
- Нативные проверки normal/429/unknown/cancel через реальный изолированный процесс и журнал: пройдены, платных вызовов 0. Повтор 429 начался через 20,016 с; учтены все 3 попытки.
- Проверены 9999/10000 символов, сохранение маршрута и промпта при повторе, неполная SSE-квитанция и отсутствие слепого повтора.
- Новый путь проверен под основными systemd-ограничениями ядра, затем повторно на установленном коде. Отдельный нативный тест подтвердил отказ записи при заполнении временного тома и его очистку.
- Реальная проверка на синтетическом документе 19117 символов: правильные 3086,26₽, ответ одной короткой фразой словами; **4 внутренних вызова,0,1393621786584₽**. Это только проверка этапа ответа: выбор шаблона повторно не оплачивался. API маркетплейсов и колонка не вызывались.
- Проверены манифест всего release, сохранность исходных каталогов, активность служб и соответствие версий работающего RPC файлу runtime-versions.

При ревью и проверках исправлены гонка завершения предыдущего исполнителя, совместимость общего recovery с прежними вызывающими компонентами и неверная классификация частичного SSE как автоматически повторяемого результата. Первая попытка установки была отклонена старым манифестом и автоматически восстановила исходную службу и промпт. После формирования полного манифеста новой сборки обе штатные проверки допуска прошли; проверки не отключались.

Включение этого маршрута не является гарантией правильности любой программы или объяснения модели. Новая инструкция дала корректный короткий текст в одном реальном контрольном случае; все возможные вопросы и голосовая приёмка этой проверкой не объявляются закрытыми. Прежний риск тихого неверного результата остаётся предметом пользовательских проверок.

**Для других исполнителей:** брать за основу `/opt/alice-market/releases/alisa-program-answer-r1-20261111`, сохранять источник патча и новую стадийную статистику. Для прямого пути обычны два вызова модели с выбором шаблона; программный путь имеет переменное число, фактическое значение берётся из журнала. Голосовая очередь, текущий номер теста и ранее принятые сценарии сохранены. Продолжение голосовых тестов — по команде владельца.
