# Обязательный мини-отчёт каждого прохода

Поручение владельца05.11.2026: в конце каждого прохода сообщать сколько реализовано, сколько осталось, что выполнялось сейчас, что сделано за проход и следующий шаг.

Использовать `CATALOG_PROGRESS_CURRENT.json`, обновлённый по readback конкретной сборки и проверенного кандидата. Единица счёта — объявленное определение показателя, сводки, формулы, табличного представления или H00. Синонимы, сочетания площадок, API-запросы и тесты не увеличивают число шаблонов. Согласованные16 бизнес-семейств и3 служебных блока — отдельная классификация.

В финальном ответе обязательно:

| Поле | Что писать |
|---|---|
| Реализовано | Число определений, включая проверенный неустановленный кандидат |
| Включено | Число определений в действующей конфигурации; это не обещание независимой числовой приёмки |
| Осталось | Готовые определения без установки/допуска плюс именованные функциональные пробелы вне счётчика; не выдавать остаток кандидата за весь будущий объём |
| Сделано за проход | Только фактически выполненные изменения/проверки; новые, включённые и только квалифицированные определения разделять |
| Что выполнялось сейчас | Конкретный блок и текущий статус, без обещания фоновой работы |
| Следующий шаг | Одно конкретное следующее действие, точная зависимость или блокер |
