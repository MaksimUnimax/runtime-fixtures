## Итог и публикация тестером

Числа групп: 70+16+24+8+12+9=139. Поля результатов изначально NOT_RUN/null. Публиковать отдельный run, не заполнять исходный план как будто он лог. Его VALID_RECORDS не является независимой приёмкой бизнес-цифр.

Результат в quality/inbox: количество выполненных/не выполненных, реальные ответы/время, ошибки, числовые сверки и конкретный следующий сценарий. Использовать прежние IDs OZCP/OZPAY/OZYOY при воспроизведении. Не закрывать per-SKU/day OZCP-002 по одной агрегированной сумме установленного B05.
