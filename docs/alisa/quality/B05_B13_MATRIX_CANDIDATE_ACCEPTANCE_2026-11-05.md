## Реализованный пакет

### B05 — четыре формы одного общего источника

1. По товарам: количества, положительные покупательские и продавецкие суммы, обратные суммы/количества отдельно, взвешенная средняя.
2. По дням: тот же смысл и контрольные суммы на оси даты начисления, не физического выкупа.
3. По товарам-дням: совпадающие суммы по двум ключам.
4. **Новые товарные строки:** отдельные записи одного SKU с разными ценами не сворачиваются в одну. Покупательская сумма строки, количество, цена продавца за единицу, продавецкая сумма строки, среднее на единицу и явное направление. Для quantity>1 среднее строки не объявляется доказанной ценой каждой отдельной покупки.

Возвраты/обратные начисления показываются отдельным направлением с модулями сумм, не как положительная продажа. Нулевой покупательский amount при положительной продавецкой строке допустим только как явное исходное число с арифметической сверкой; пропущенный/null amount — ошибка. Дни без строк не дополняются выдуманными нулями. Незавершённый текущий день не выдаётся за окончательный период.

### B13 — текущие статусы и явное покрытие кампаний

Сохранён существующий запрос статистики текущих активных/приостановленных кампаний. Добавлены:
- **Инвентарь кампаний и статусов** — отдельный исходный блок, без fullstats.
- **Сводка выбранных активных/приостановленных кампаний** — сумма только этой явно названной группы.
- **Статистика текущих статусов7/9/11** — включает завершённые, но не обещает все удалённые кампании или историческую активность.

Список51 ID разбивается общим матричным chunks в50+1. Полный ответ требуется по всему запрошенному набору; отсутствующий/чужой/дублированный ID, null или неполная страница не превращаются в0 или готовый частичный итог. При наличии daily детализации проверяются даты, уникальность дней и согласованность шести сумм/счётчиков с итогом кампании. Отсутствующая необязательная детализация не создаёт выдуманный дневной ряд. Явный currency в ответе должен совпадать с подтверждённой валютой магазина; если поле отсутствует, остаётся прежний квалифицируемый контракт валюты кабинета, а не новая гарантия источника.

Статистический spend не добавляется повторно к финансовому рекламному расходу. Отсутствие fullstats не доказывается нулём даже у кампании без очевидной активности.
