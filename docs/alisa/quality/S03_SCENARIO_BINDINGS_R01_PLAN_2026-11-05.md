## Цель этого прохода

Заменить прежний synthetic bridge настоящим общим runtime-модулем привязки owner facts к quantity/date источнику и составному сценарию. Получить исполнимую связку immutable pin → owner resolve → количество каждой строки на дату → COGS/точные period inputs → существующий report completeness gate → табличный расчёт с явными единицами и происхождением.

Сценарии C-UE01 задаются JSON: без отмен (контрфактическое выполнение исходных единиц) и с фактическими отменами/возвратами (оставшиеся единицы). Исходная себестоимость каждой физической единицы сохраняется; per-original-order allocation выводится отдельно. Изменение себестоимости внутри периода выбирается по квалифицированной дате строки, не усредняется. Полностью отменённая строка не требует выдуманной себестоимости, но реальные не-COGS расходы не удаляются.

Источник предоставляет проверенный нормализованный cohort и отдельно суммы/контроли расходов с точным scope/period/hash/provenance. Его полноту и cardinality подтверждает trusted callback. При совпадении номеров/названий строки не соединять по догадке. Обходить отсутствие source adapter/authority посредством доверия JSON запрещено.

Реклама, полнота расходов и контроль пересечения источников обязательны. Missing owner costs/tax имеют omissions, не0. Точное period input не распределяется на другой интервал. Actual, API/official estimate и period allocation сохраняются раздельными метками. Unknown cancellation stage не добавляет ручной gate: в последующей source-привязке разрешённый владельцем тариф возврата должен разрешать такой случай. Сам source/tariff adapter и live forecast-приёмка не выдаются за готовые до отдельной реализации.

Формулы/списки компонентов/quantity selectors в JSON; Python реализует ограниченные общие операции без веток по имени C-UE01/площадки/метрики. Использовать существующие owner resolver, matrix arithmetic и ReportContracts, не переписывать их для успешных тестов. Pin покрывает все входы и сценарную политику; повтор execute/read заново проверяет права и тот же snapshot.
