1. В information_catalog добавлен общий тип feature-ссылки на dataset query; H00 без HTTP строит разрешённый план и проверяет актуальный scope, все нужные операции, hashes и source deny. Список возможностей меняется данными, не веткой Python для каждой площадки/фразы.

3. Общий rejection_reply применяется и прямым ingress, и неуточняющим диалоговым отказом. Для известных catalog codes/aliases всегда возвращаются reason/next_action/cause_status, text==tts. Существующие специальные уточнения даты/метрики сохранены.

Изменены ровно шесть manifest-файлов: engine.py, dialogue.py, information.py, failure_explanations.py и два информационных JSON-каталога. HTTPTransport, бизнес-рецепты/показатели/формулы, квалификация, квоты и payload маркетплейсов не изменены.
