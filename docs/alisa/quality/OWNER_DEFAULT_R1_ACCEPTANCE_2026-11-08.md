## Что и зачем изменено

**Общая себестоимость.** Ввести сумму за физическую единицу и период действия можно один раз для магазина, не перечисляя товары. В модели это явное правило all-products, а не тысячи сгенерированных строк. Оно предназначено и для новых товаров, которые появятся в проверенных данных источника.

**Исключения.** Отдельную себестоимость можно указать для выбранного товара. Она перекрывает общую только на своём интервале дат. Ноль и явно неизвестное значение исключения не заменяются общей суммой. За пределами покрытых интервалов остаётся пропуск. Общий resolver и новый матричный кандидат проверены на этих случаях; рабочий аналитический runtime этим проходом не переключался.

**Выбор товара.** Вместо поля ручного числового SKU показан список названий и артикулов из подключённого магазина. Идентификатор передаётся программно. Для общей цены каталог вообще не требуется. Индивидуальное сохранённое значение не удаляется, если его товар пока не загружен в список. Поиск действует среди загруженных страниц, следующие страницы дочитываются кнопкой.

**Сохранение.** Существующие явное подтверждение, expected_revision, Web Lock, lost-ACK status/recovery и блокировка при отказе browser storage сохранены. Налог и собственные расходы по-прежнему точные суммы за период, не процент или автоматически распределённый месяц. Нет r9/default250 и выдуманных затрат.

Ранее сохранённые значения не мигрировались и не переутверждались автоматически. Новый каталог owner-inputs имеет новую версию; перед использованием этой версии в последующем расчёте нужны актуальные подтверждённые параметры. Старое подтверждение не объявляется новым без действия владельца.

## Каталог и границы безопасности

Это **read-only справочная операция выбора товара**, а не финансовый отчёт. Она добавлена в существующий peer-checked Unix IPC проверки магазина, не в обход аналитического Worker для расчётов. Используется прежний bounded shared HTTP, фиксированные endpoints, общий конечный deadline страницы, без произвольных URL и автоматических повторов.

Платформа проверяет сессию, ownership, ACTIVE store и CONNECTED seller/WB credential до вызова; после ответа снова проверяет текущую ревизию и права. Сетевой вызов не удерживает DB-транзакцию. Ключи остаются на серверной стороне и не попадают в браузер, курсор или журнал. Курсор подписан и привязан к среде/магазину/credential/security revision, срок900секунд.

Справочные запросы ограничены по проверенному аккаунту: не чаще одной страницы в3секунды, до100страниц/24часа. Страница до20товаров; Ozon требует максимум2HTTP (product/list и product/info/list), WB —1HTTP карточек. Это отдельный ограничитель справочного просмотра, **не утверждение о расходе из аналитического calls/rates ledger**. Расчётные квоты и очередь не изменены.

Для Ozon product_id связывается с SKU из ответа, не подставляется вместо него. Проверяются состав ID, total/cursor и полнота страницы. Для WB каталог активных карточек не выдаётся за содержимое корзины. Ошибка/неполная страница не превращается в успешный пустой каталог. PERFORMANCE не нужен для выбора товаров, но прежние требования к нему для C-UE01 не ослаблены.

## Действия владельца — перед следующим шагом

1. Открыть https://alisa.octoport.ru/app/owner-inputs и выбрать магазин. При необходимости войти обычным способом. Нажать «Добавить общую себестоимость», выбрать «Сумма известна», указать реальную сумму за единицу и даты действия. **Ожидается общая строка без выбора SKU/товаров.**
2. Только для товаров с другой стоимостью нажать «Добавить исключение для товара». Дождаться каталога, выбрать название/артикул, указать сумму/даты. При необходимости использовать поиск среди загруженных товаров и «Показать ещё товары». **Ожидается выбранный товар без ручного ввода числового ID.** Если всё одинаковое, исключения не нужны. При недоступном каталоге общую стоимость можно сохранить отдельно, но не выдумывать индивидуальную связь.
3. Проверить строки, поставить галочку и нажать «Подтвердить и сохранить параметры», затем «Обновить версию». **Ожидается сообщение «Параметры подтверждены. Версия N» и сохранённые строки после перечитывания.** При потерянном ACK — «Проверить сохранение», не новая правка. Передать в чат магазин/версию либо точный текст ошибки; никаких паролей, кодов и ключей.
