# Уточнение сетевого бюджета Q01 до запуска

Сетевых запросов в этом проходе ещё не выполнялось. После чтения реальной схемы (страницы metadata по100 записей) верхний предел изменён с12 на **16 физических read-only вызовов**. Deadline240 секунд и ожидание одной квоты<=30 секунд сохраняются. Это заранее определённая верхняя граница, не обход429 или повышение штатных daily limits.

Первые полные metadata-ответы за03–04 ноября используются одновременно для сравнения27 строк tester J01 и как часть окна соединения. Источник начислений — по одному дню, обе схемы отправлений — с историческим окном. Максимум два запроса WB: inventory и fullstats для допустимых статусов при наличии бюджета. Если не удаётся получить все страницы в лимите — INCOMPLETE, квота/полнота не ослабляются.

Protected reference.json содержит только хеши нормализованных полей и количества24FBO/3FBS из tester report, не идентификаторы/денежные строки/токены. Старый приватный отчёт не копируется и не меняет TTL. Новые raw ответы по умолчанию только в памяти. Итоговая квитанция — независимый same-source recalculation, не независимый кабинетный экспорт и не новая внешняя приёмка Алисы.
