## Исполнение после нового допуска

1. Свежие версии, один автор, WIP, locks, отсутствие rollout и временных proxy/drop-in. Проверить точные UID, DNS и PG/API/SMTP адреса; при расхождении остановиться, не расширять allowlist. Если таблица уже существует — не присваивать владение и не удалять её; сначала выяснить исход.
2. Снять read-only baseline существующих nft tables/rules. Поднять собственный конечный loopback listener127.0.0.1:18299 и подтвердить доступ от observer до фильтра; не обращаться к чужому API ради свидетеля. Проверить точный hash файла и повторный `--check`.
3. В одном процессе с собственными locks установить только указанный новый объект через `nft --file <точный файл>`. Время smoke ограничить180 секундами; обработчик TERM и `finally` удаляют только созданную этим процессом таблицу. Не вводить постоянный daemon, расписание, сетевой proxy или credentials.
4. Под собственным web UID подтвердить отказ к своему loopback listener и к зарезервированному внешнему адресу, с ростом именно deny counter. Затем пройти свежий browser→identity email-code→BFF→API→PG→/app под действующим фильтром. Подтвердить те же Person/Customer/Tenant, отсутствие дубля и сохранность профиля; разрешённые upstream counters должны вырасти.
5. В `finally` остановить только свой listener и удалить только `nft delete table inet alisa_s02_egress_probe_6ae34835`, если именно этот процесс создал её. Проверить отсутствие таблицы, неизменность чужих rules и доступность собственных служб. Сохранить безопасный receipt без контактов/кодовых значений/токенов/ключей. При ошибке cleanup остановить зависимую работу и сообщить точный оставшийся объект; не применять общий flush.
6. Передать результат существующему независимому reviewer для итогового installed verdict точного source/package. Только после закрытия этого блока и принятия S02 перейти к source-разработке S03.

Следующее допустимое окно: сразу после явного допуска на это дополнение и успешной свежей предпроверки. Повторная установка пакета, новые миграции/rotation и продление HTTPS для него не нужны. Альтернатива — отдельно восстановленная поддержка доказуемого per-unit deny; автоматических повторов не запланировано.
