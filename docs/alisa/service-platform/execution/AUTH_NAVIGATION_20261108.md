Первый baseline-запуск остановился до навигации из-за отсутствия пути к имеющемуся браузеру. После указания `PLAYWRIGHT_BROWSERS_PATH` обычная регистрация прошла. Старые неуспешные source-кандидаты не устанавливались.

Рабочие файлы браузера помещены в приватный systemd RuntimeDirectory на `/run` tmpfs, включая TMPDIR/HOME/XDG. Проверены тип tmpfs, свободные 128 MiB, запас памяти, размер сохраняемого cookie JSON не более 64 KiB и диск после сохранения.

Повторный browser unit: RuntimeMaxSec 180, MemoryMax 1536 MiB, Swap 0, Tasks 512, TimeoutStopSec 5, KillMode control-group.
