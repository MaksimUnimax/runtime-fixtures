# AL-S02 — обычная регистрация и вход по настоящей почте

Прямое поручение владельца 5 ноября 2026: сделать обычную регистрацию/авторизацию, вместо входа только одного приглашённого адреса.

Включаемый режим ALISA_REAL_LOGIN_OPEN=1 принимает настоящие адреса без предварительного списка на identity, в отправителе почты и при создании сессии кабинета. Транспорт — действующая почта Октопорта с проверяемым STARTTLS. Код одноразовый, 10 минут, максимум 5 попыток; запросы кода ограничены по контакту и IP. Подтверждённый email не объединяет аккаунты разных продуктов и не выдаёт права магазина или администратора.

Три компонента используют один флаг: identity, platform, web. Без флага сохраняется прежний режим приглашений или синтетический режим. Включение на production не входит в эту правку: действующие stage-адреса остаются прежними. Открытие обычной регистрации на этих адресах прямо разрешено текущим поручением владельца. Схема БД не меняется.

Проверки кандидата: существующие source/unit, PostgreSQL, HTTPS/OIDC/BFF, staff/MFA и отдельный полный прогон --open-registration без списка приглашений. Две новые реальные формы адресов example.test проходят signup → код → свой кабинет; повторный вход сохраняет customer/tenant. Только тестовый процесс доставляет эти фикстуры в loopback SMTP; в продуктовый код такого обхода не добавляется.

Перед закрытием установить точный проверенный пакет и пройти новый реальный адрес владельца через Gmail, повторный вход, сохранность и приватность. Данный исходный документ сам по себе не подтверждает установку или готовность. Итоговая квитанция и ручной адрес входа будут добавлены после проверки.
