## Остаток до приёмки площадок

WB может получить подтверждение только из аутентифицированного `sid`. Seller binding по умолчанию не квалифицирован: даже успешный `seller-info` не включает флаг подтверждения кабинета до отдельного доказательства пары Client-Id/API-key. Performance token не доказывает тот же Seller кабинет. Эти ограничения сохранены в установленном CLI; ложный `CONNECTED` не выдаётся.

Реальные ключи старого runtime/расширения не импортировались. Реальная проверка должна пройти через ввод владельцем в его клиентском кабинете; ключи не передаются в чат или отчёт. До этого полная AL-S05 и LIVE_OWNER/PRODUCTION acceptance не заявлены.

## Ручная проверка

1. Открыть страницу магазинов и войти в свой обычный клиентский кабинет.
2. Выбрать площадку, ввести название и свой API-ключ; для Ozon также Client ID. Нажать «Сохранить и проверить».
3. Проверить карточку и сообщение о результате. Сообщение «Не удалось подтвердить кабинет площадки» не означает неверный ключ; для Ozon подтверждение привязки пока остаётся открытым.
4. Обновить страницу: карточка должна сохраниться, введённый секрет не должен показываться. Изменить название и голосовой псевдоним.
5. При необходимости отключить или удалить магазин. Его ключи отзываются; действие относится только к выбранному магазину.

Безопасные фактические receipts находятся в [каталоге rollout](s05-installed-20261106/PROGRESS.md). Private env, browser state, signed download URLs, schema backup и ключи в Git не помещались.
