# AL-S04 · бесплатный срок доступа

На https://alisa.octoport.ru/app/access включён раздел «Доступ». Администратор может выдать GIFT/COMPENSATION одному клиенту или выбранному списку; клиент видит срок, основание, историю и уведомление в кабинете. Preview фиксирует даты; повтор команды не добавляет дни ещё раз. Отзыв касается только неиспользованного остатка выбранного предоставления.

**Статус: READY_FOR_OWNER_TEST.** Реальная выдача через переданного OWNER ещё не проверялась. Клиентское чтение на установленной версии подтверждено; сценарий «выдать семь дней → клиент видит тот же срок» проверен отдельно в source/package. Эти области не объединяются в live-grant PASS.

Клиентская проверка прошла настоящий вход через id.octoport.ru, открыла «Доступ» из кабинета, сверила страницу с authenticated API и отвергла чужой tenant. Клиент не получил staff authority; его доступ остался NOT_PROVISIONED с пустой историей, поскольку выдачи не выполнялись.

Независимый reviewer проверил исходник и архив, процедуры, установленный пакет, конфиги, migration/ACL и готовность служб. Все четыре службы READY, канонические HTTPS адреса доступны. Выдачу через реального OWNER проверяет владелец. Текущий поток не возвращал тестовую роль и не выполнял handover/canonicalization.

## История и ресурсы

Сохранены исходный failed PostgreSQL receipt и исправление, browser locator failure и исправление без удаления assertion, REWORK первого procedure review и принятое R2. Первая попытка остановить уже inactive collected window завершилась FAILED до readback cases; R2 обработал уже освобождённое окно и прошёл. Исходные результаты не переписаны.

Повторяемые зависимости своих неактивных версий объединены по полному равенству файлов. Активные inodes, архивы, данные и пути версий не изменялись/не удалялись. Metadata сохранена приватно; nlink/ctime и timestamps неактивных dependencies меняются, ctime не восстанавливается. Новый пакет установлен обычным копированием. Финальный резерв: 3682 MiB диска, 583097 свободных inodes, 5806 MiB available RAM.

Окно g003 завершилось штатно, ограниченные процессы закрыты. Поздние чтения не считались выполненными под lock. Реальные выдачи, платежи и массовые письма не запускались.
