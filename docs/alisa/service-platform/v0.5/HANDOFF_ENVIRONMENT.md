**Не требовать здесь готового CI, работающих приложений/миграций, deploy и business DB:** их создаёт AL-S00. В ENV подтверждается доступная инфраструктура и разрешение, в AL-S00 — работающая реализация. Термин DEV_READY из v0.4 заменён на эти два разных результата.

## 3. Инфраструктурные проверки

ENV-T01: DNS имена точные, нет неожиданного wildcard/AAAA. ENV-T02: обычная TLS-проверка без -k. ENV-T03: setup marker показывает свой host/environment и application_ready=false. ENV-T04: ACME/renewal только новых сертификатов. ENV-T05: текущий Octoport/alice-lab без изменения. ENV-T06: раздельная среда, доступ и секреты. ENV-T07: измеренная пригодность ресурсов и runner. ENV-T08: паспорт подтверждён и передан без secrets.

Только после INFRA_READY прикладной исполнитель начинает AL-S00. После его приёмки FOUNDATION_READY открывает AL-S01. Production-разрешение не возникает из stage-готовности. Пароли, ключи и tokens в этот документ не записываются.
