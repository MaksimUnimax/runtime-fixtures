# Качества, риски и точки решения

Все строки — проектные проверки, не выполненные PASS. Числа из старых документов остаются целями испытаний, не SLA.

| Качество | Условие | Измеримый результат | Где проверяется |
|---|---|---|---|
| Воспроизводимость | Новый проверяющий/чистый checkout | Build/deploy из lockfiles и runbook без скрытых файлов | AL-T00-01,18 |
| Раздельность | Другой продукт/его БД недоступны | Каркас и позже пользовательский путь Алисы продолжают работать | AL-T00-15, AL-S07/19 |
| Безопасные данные | Роль пытается читать другой контур | Отказ DB и API, нет побочного эффекта | AL-T00-08, поздние tenant tests |
| Достоверное здоровье | DB недоступна | Readiness 503, не ложный READY | AL-T00-07 |
| Восстановление | Worker оборван после acceptance | Тот же job/probe без дублирования | AL-T00-06, AL-S10 |
| Управляемый выпуск | r1→r2→r1 | Readback версии, совместимые данные сохранены | AL-T00-11 |
| Совместимость | Пакет матрицы изменён во время задания | Старое задание остаётся на закреплённой версии | AL-S13 |
| Деньги | Повторы/перестановка callbacks | Один подтверждённый платёж — один grant | AL-S20–23 |
| Приватность | TTL/restore | Истёкшее и отозванное не становится доступным | AL-S15/17/23 |

## Риск-реестр

| ID | Риск | Мера и решение |
|---|---|---|
| RSK01 | 1 CPU/~1 GiB исторического хоста недостаточно | До AL-S00 паспорт мощности, build отдельно, измерение; при нехватке отдельный host/resize |
| RSK02 | Две версии требований живут параллельно | Active v0.5 имеет явный приоритет; источники immutable; data JSON и Markdown сверяются |
| RSK03 | Каркас превращается в бесконечную платформу | Только перечисленный technical E2E и 18 критериев, бизнес-модули по первому потребителю |
| RSK04 | Common identity создаёт скрытую зависимость от старого Octoport | Новый самостоятельный authority, старый продукт подключается только позже |
| RSK05 | Несовместимая auth/DB библиотека | Версии и custom UUID model квалифицируются в 00/02, не копируются по памяти |
| RSK06 | Runtime меняется параллельно | Pinned contract/version и один adapter owner; без прямого доступа к SQLite |
| RSK07 | Инженерная проба становится публичной дырой | Stage-only, ingress+upstream auth, fixed schema, prod 404, off после проверки |
| RSK08 | Платёжный/юридический договор не определён | Не мешает 00–19; блокирует реальные продажи; defaults не угадываются |
| RSK09 | Неподдержанные вопросы теряются/содержат secrets | Очищенный durable outbox, metadata fallback, loss counters и отдельные TTL |
| RSK10 | Нет возможности GitHub write в текущей сессии | Локальная поставка + проверенный publisher; отсутствие commit явно отмечено |

Риск не закрывается текстом «учтён»: нужны фактическое решение, ответственный, дата, тест и evidence. Незакрытые D01–D12 остаются в DECISIONS_AND_GATES; новые вопросы о toolchain/resource назначены AL-S00/ENV-00.
