## План и сохранение хода

- Период: 01–31.10.2026, последний полный месяц в текущем контексте.
- Один источник: POST /v1/finance/accrual/by-day, дата начисления. Нельзя подставлять заказанные единицы из другой временной оси.
- Один логический отчёт, запросы к источнику отдельно по датам с полной пагинацией. Это не обещание одного физического HTTP за месяц.
- Среднее рассчитывается кодом через суммы и количества одной выборки; DeepSeek не выполняет арифметику.
- Многотоварные строки, количество >1, возвраты, валюты, полнота и повторные курсоры проверяются до итогов. Непроверенный смысл поля не подменяется догадкой.
- Первая дата 01.10 вернула HTTP 200 и полную страницу. Идёт оставшийся сбор.
- Журнал каждого вызова атомарно сохраняется в закрытом `/var/lib/alice-lab/probe-reports/ozon_price_volume_202610_manifest.json`; ответы там же под префиксом `ozon_price_volume_202610_`, срок хранения по существующему таймеру 24 часа.
- Выгрузка и вычисления вне работающего навыка. Runtime, службы, OAuth и чужой релиз v0.10 не меняются.

Денежные значения, товарные строки, приватные номера отправлений и credentials в публичный Git не публикуются. Финальный документ будет дополнен временем полной сборки, числом HTTP, методикой и результатом квалификации.
