## Воспроизведённый дефект до исправления

В `ScalarMatrix.decode` checks для `workflow.steps[*].guards` выполнялись только на стадиях с final=false. На стадии final=true сначала шёл общий source-decoder, объявленная guard не исполнялась. Это нарушает ADR-006: матрица не должна содержать условие, которое программа молча игнорирует.

Контрпример выполнен без сети, credentials и live-конфигурации: в копии каталога final download получил guard `test=false`, code=DECLARED_FINAL_GUARD. С правильным pinned progress вызов `decode([])` вернул complete=true вместо отказа. Никакие рабочие финансовые результаты этим тестом не менялись.

## Требуемое исправление и проверка

Применять guards для каждой стадии, включая final. На последней стадии поддержать объявленное предельное число шагов и страниц: завершение либо следующая страница должно расходовать один общий workflow-step, без сброса version/scope pin. Общие правила, без ветки по WB/Ozon.

До релиза проверить false/true final guard, неверное состояние/версию/магазин, ограничение последней пагинации, новый workflow только JSON, отсутствие сети/секретов и сохранность прежних стадий. Дефект не объясняется API или пользователем; это пропущенная отрицательная проверка исполнителя. Итог после изменения записывается отдельно, этот документ не является PASS.
