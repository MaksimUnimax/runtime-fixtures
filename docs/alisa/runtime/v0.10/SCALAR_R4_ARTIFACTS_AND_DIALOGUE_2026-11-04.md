## Действующая цепочка уточнений

Через штатный UID web и существующий gateway, отдельная беседа:
1. «Дай продажи за вчера» → METRIC_AMBIGUOUS, сохранено 2026-11-03.
2. «выкупы» → COHORT_REQUIRED, сохранён тот же период.
3. «Все что выкупили вчера» → смысл события принят; OZON_EVENT_SOURCE_UNAVAILABLE с предложением отдельного WB. Не меняет дату и не выдаёт иной показатель.
4. «только WB» → READY/HIT готового событийного отчёта, период 2026-11-03.
5. «результат» → сохранённый отчёт, text==tts.

Новые HTTP по этой цепочке не понадобились: используется точное полностью готовое задание. Полный исходный вопрос повторять не нужно. Это действующий сервис, но не новый внешний запрос из консоли Яндекса и не звук колонки. Текст старой подсказки выбора оси содержит пример «по дате заказа»; готовность событийного источника WB этим не отменяется — явная событийная реплика теперь принимается.
