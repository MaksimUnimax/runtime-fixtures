## Установка

Перед изменением: повторно проверить манифест, собственный lock, ExecStart build8, enabled/access и отсутствие QUEUED/RUNNING. Не перехватывать соседние ветки/ценовое исследование. Изменяются только qualifications для проверенных каталогов и table_capabilities существующих магазинов. Статус READ_ONLY_CANARY сохраняется, не выставляется PRODUCTION_VERIFIED. OAuth, account stores, credential references, бюджеты и таймеры не меняются.

Штатно остановить только alice-market; перепроверить отсутствие racing job; сделать приватную SQLite backup. Изменить конфигурацию атомарно с сохранением владельца/прав; добавить отдельный systemd drop-in на r4. Запустить и подтвердить действующий путь, сокет и диагностику. При ошибке запуска вернуть конфигурацию из памяти, убрать только новый drop-in и включить build8. Не откатывать SQLite поверх уже принятых новых сообщений.

Сохранить приватную квитанцию с хешами, прежними qualification metadata для безопасного отката и фактом неизменности аккаунтов/секретных ссылок. Config/token values в Git не публиковать. После включения выполнить адресные read-only задания через рабочий gateway и проверить ledger, READY/полноту и text/tts, а не только health. Обычная консольная приёмка остаётся отдельной.

Файл и параметры проверены; штатный отдельный запуск существующего test_scalar_resume.py успешно выполнился. Это не доказательство причины отказа. Исходники восстановлены из доступных сохранённых материалов с контрольными суммами, не из предположений.
