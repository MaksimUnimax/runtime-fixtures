# Точка входа: матрица, а не обработчики под каждый источник

04.11.2026. **Рабочий навык остаётся 0.9 build8. Кандидаты 0.10 не активированы.** Прежнее предложение «просто установить events-rows-r1» больше не является планом: владелец потребовал исправить архитектуру до дальнейшего выпуска.

## Читать до изменений

1. [ADR-005](ADR_005_MATRIX_ONLY_EXTENSION_CONTRACT.md) — обязательное требование: совместимые источники, формулы, шаблоны и разрезы добавляются матрицей без новой Python-ветки.
2. [RCA-001](RCA_001_ARCHITECTURE_DRIFT_AND_WORK_RULES.md) — исполнитель начал с отдельных сценариев, а функциональные тесты ошибочно заменили архитектурную приёмку. Документация была; не хватало обязательного исполняемого gate.
3. [Фактический контракт](matrix_refactor/MATRIX_BINDINGS_SPEC.md) — общий bounded interpreter, формат JSON, безопасность и границы.
4. [Текущая приёмка](MATRIX_REFACTOR_ACCEPTANCE_2026-11-04.md) — что действительно переписано, 717 тестов, JSON-only proof и OPEN-пункты.

Каждая правка: ID требования → изменение матрицы или обоснованный новый общий примитив → тест → доказательство. Нельзя переопределять требование ради уже написанного кода или считать число зелёных тестов доказательством универсальности.

## Что теперь есть

В неактивной `/opt/alice-market/releases/20261104-v010-matrix-refactor-r2` четыре новых табличных API перенесены на один source interpreter. Полные request/response/page contracts находятся в source_matrix.json, маршруты — table_catalog.json. Два прежде неизвестных синтетических источника с другими полями и offset/cursor действительно добавлены только JSON: 24 Python-файла остались одинаковыми, очередь/транспорт/расчёт прошли. На сохранённых настоящих ответах проверены Ozon и WB; новый внешний HTTP в этой работе не выполнялся.

## Что НЕ закрыто

Старые scalar providers/finance_stock/registry, рекламный auth workflow, async stock report и общий приём новых semantic metrics ещё не мигрированы. M09 (новый live-canary/активация/настоящая консоль) открыт. Наличие общего движка четырёх методов не даёт права говорить «вся система теперь расширяется только матрицей».

Прежний staged events-rows-r1 и собственный lock сохранены. Чужие изменения ветки/ценовые исследования не трогать. Бизнес-данные с TTL могут исчезнуть; не обещать вечную доступность probe JSON.

## Проверка пакета

Полный итоговый ZIP `ALISA_MATRIX_ONLY_REFACTOR_CANDIDATE_2026-11-04.zip` содержит весь связанный исходник, тесты и manifest. Запустить в чистой копии:

```sh
python3 -B architecture_gate.py
python3 -B run_checks.py
```

M01 имеет явно ограниченный scope. 717/717 не закрывает оставшиеся миграции автоматически. В Git generic Python опубликован базой плюс MATRIX_SCHEMA_HARDENING.patch; полный ZIP и staging уже содержат применённые поправки. Папка matrix_refactor не является автономным установщиком.

**Следующее действие:** продолжать перенос legacy-контрактов и проверять matrix-only gate, а не добавлять очередной endpoint-specific обработчик и не устанавливать старый архитектурно неподходящий кандидат.
