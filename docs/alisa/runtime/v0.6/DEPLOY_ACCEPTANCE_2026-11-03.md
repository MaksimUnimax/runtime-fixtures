## Граница доказанного
Реальный авторизованный пользовательский проход **через консоль Яндекс Диалогов после этого развёртывания пока не наблюдался**. Публичные проверки без токена подтверждают card связывания, отсутствие card на неподдерживаемой поверхности, чужой skill_id -> HTTP 403. Изолированные проверки авторизованного webhook (9/9) проведены с временной БД и синтетическими токенами, без сети.

Попытка вставить временный access token в действующую БД для программной публичной проверки была отклонена инструментом до исполнения. Это действие не повторялось другой формой или транспортом. Настоящие ключи и токены в эти документы не переносились.

Ozon currency не подтверждена; нельзя складывать его денежную сумму с WB RUB. Данные не сверены с личными кабинетами. Прочие KPI (ДРР, реклама, прибыль, выкупы, остатки, фильтры) пока не реализованы; система отказывает без подмены.

## Инструкция владельцу в консоли Яндекса
1. Открыть приватный навык «Октопорт маркет» → «Тестирование», уже существующую привязанную учётную запись.
2. Отправить `диагностика аналитики`: ожидание — «Матрица 0.6», реальные запросы в тестовом режиме.
3. Отправить `сводка заказов за октябрь 2026 на озоне и вайлдберриз`: ответ должен быстро принять задание, либо отдать exact-cache.
4. Отправить `результат`, при необходимости повторить после выполнения; должен вернуть данные обеих площадок. Не создавать дополнительный marketplace HTTP повторным «результат».
5. Отправить `ДРР за октябрь на Озоне` и `сумма заказов за октябрь кроме артикула А`: явный отказ без подмены.
6. Для диагностики передавать только ответ `Response`/видимый текст, не `session.user.access_token`.
