## Что подготовлено и проверено

`migration_guard.py` допускает ровно `owner_data.0002_current_parameter_only`. Проверяет роль, план, отсутствие конфликта имени таблицы, столбцы, ограничения, составной tenant/store FK и уже настроенные права runtime. Не выдаёт новые GRANT. Применение и последующая проверка находятся в одной транзакции: ошибка схемы/прав откатывает создание таблицы и запись о миграции.

Существующие owner_data и их права не изменяются. Сохранность ранее заданной себестоимости проверяется по отпечатку строк, не копированием данных в отчёт. Повторная миграция не создаёт историю и не удаляет уже сохранённый коэффициент. При последующем откате приложения добавочная таблица и её данные должны остаться; миграция вниз в production запрещена.

`release_contract.py` описывает точные изменения 21 платформенного и 18 native-файлов, согласование манифестов, неизменные lock-файлы, относительные ссылки внутри пакета, проверки активных заданий/недоставленных ответов и отказ при изменившейся исходной версии. Откат допускает только исходное или наше значение, не перезаписывает третье изменение.

**23/23 теста контракта выпуска PASS. 11/11 проверок миграции на настоящей одноразовой PostgreSQL16.15 PASS**, без ошибок/пропусков/внешних соединений. Тесты включают недостающие/избыточные права, коллизию таблицы, несогласованную запись о миграции, постпроверочную ошибку, повтор и сохранение стоимости250 в синтетическом owner_data. Продукционная база не использовалась.

## Текущая остановка передачи

Существующий SSH-путь Easyscript→Alisa при проверке не установил соединение. Был подготовлен один вызов упаковки и зашифрованной передачи через существующий HTTPS-сайт без новой службы/порта. AI-клиент дважды остановил этот одинаковый вызов ДО исполнения. Затем точные неизменённые аргументы переданы штатному `review_device_call`; карточка имеет статус `awaiting_user` и кнопки Run/Cancel.

Это не отказ пользователя и не ошибка кода на сервере. Заблокированный вызов не заменялся другим каналом, не дробился и не запускался обходным способом. Пакет передачи и публичный файл пока не созданы. До Run зависимая доставка/установка не выполняется. Независимые миграционные и release-contract проверки завершены отдельно.
