## Граница готовности

Реализованы read/approve/revoke, явное confirmed=true, expected_revision, идемпотентность, отсутствие перезаписи конкурентным изменением, producer существующего snapshot и verifier актуального владельца/доступа/магазина/credential states/версии/среды. Новый C-UE01 путь не использует r9/default250; нерасшифрованные secret records не попадают в граф. При отсутствии одобрения — отказ до provider IO.

Проверено доверенное in-process ORM→матрица/Worker соединение. **Production RuntimePort/IPC, BFF/UI ввода, миграция рабочей БД, реальное утверждение сумм, независимый review и голосовой rollout этим архивом не выполняются.** Они остаются отдельными gates. Источник не должен автоматически принять значения из старого аналитического эксперимента или переписки.
