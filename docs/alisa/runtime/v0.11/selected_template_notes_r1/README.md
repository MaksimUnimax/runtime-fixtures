# Пояснения только явно выбранных шаблонов

Основание: прямое уточнение владельца 09.11.2026. База установки — alisa-accrual-note-r1-20261109. Раньше _finish_fragment собирал notes по completed_fragments и dependencies(), поэтому в финальный ответ попадали комментарии базовых и вложенных шаблонов. Этот старый режим заменён.

Теперь источник речевых пояснений — только plan.selection.invocations, то есть шаблоны, явно указанные моделью. Развёрнутые обработчиком зависимости выполняются как прежде: сервер вызывает API, принимает ответы, выполняет свой расчётный план и собирает данные для одного финального вызова модели. Сеть и расчёты по частям выполняет обработчик, модель не вызывается после каждой части. Обычный успешный путь сохраняет два модельных вызова: выбор → обработка источников сервером → общий ответ.

- При выборе базового шаблона передаются его notes.
- При выборе составного — только его notes. Базовые и вложенные notes не наследуются; пустые notes не заменяются пояснениями зависимостей.
- Несколько явно выбранных шаблонов сохраняют собственные notes, каждое ID один раз. Если базовый выбран отдельно рядом с составным, он сохраняет право на собственное пояснение.
- Каталог для выбора и справки не содержит речевых notes: они нужны только при формировании ответа по явно выбранным шаблонам. Назначение, тип, параметры, доступность, зависимости, метрики и серверные ограничения сохранены.
- Полные разрешённые ответы API не изменяются. Снимок выбранных комментариев сохраняется до первой финальной отправки и повторно используется при 503/перезапуске; повторного чтения API ради пояснений нет.

B08.finance_accrued обновлён до версии 3. Указание для озвучки сокращено: один короткий ответ с периодом и итоговой суммой финансовых начислений; подробности о банковских выплатах — только по вопросу пользователя. Остальные 84 шаблона и вычислительные параметры этого шаблона не изменены. template_patch.json фиксирует SHA256 исходного/нового каталога и новую запись; это единственное изменение данных каталога.

Регрессия покрывает собственный комментарий составного, отсутствие запасного комментария базового, вложенные композиции, самостоятельный выбор базового рядом с составным, отсутствие notes у селектора/справки и неизменный снимок финального повтора. Голосовые тесты остаются остановленными по команде владельца. Платные проверки не запускаются автоматически.

Установлено: `/opt/alice-market/releases/alisa-selected-notes-r1-20261109`, исходный коммит `61b5976369b959bdffda8c271d6ca68d058f906a`. Проверки: 1839 основных + 87 наборов данных = 1926 PASS; 75 прицельных входят в основной прогон. Сервис active, манифест проверен, предыдущая версия не изменена. Изменения прошли ревью структуры потока и передачи комментариев. Голосовой прогон после установки не запускался по команде STOP владельца.
