Обращения к модели на запрос за 7 дней

Загрузка статистики…

Учитываются попытки отправки к модели, включая повторы и неудачные попытки. Среднее — все обращения за период, делённые на принятые аналитические запросы за тот же период. Запросы из кеша входят с нулём новых обращений; служебные команды и повторная доставка исключены. При сетевом сбое факт списания провайдером может быть неизвестен. Записи удаляются через 7 дней; очистка выполняется каждую минуту и при запуске службы.
