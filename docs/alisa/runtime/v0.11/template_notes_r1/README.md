# Пояснения выбранного шаблона в финальном ответе

По прямому указанию владельца B06.finance_storage_cost обновлён до версии 2: в поле notes указано, что услуга Ozon «Размещение товаров на складах Ozon» — это расходы на хранение. Отсутствие буквального названия «хранение» не означает отсутствия этих данных. Меняются только notes/version этой записи; остальные 84 определения, источники, параметры и поля неизменны.

Общая передача: после завершения источников template_runtime собирает пояснения выбранных шаблонов и их зависимостей в template_context с ID, версией, назначением и notes. model_answer получает этот снимок рядом с исходными разрешёнными API-responses. Это деловой контекст из шаблонов, а не дополнительная настройка общего промпта и не серверное переписывание ответа. Система делает два модельных вызова в обычном успешном пути.

Пояснения чужих шаблонов не добавляются. Пустой набор notes не меняет прежний payload. При повторе финальной генерации используется сохранённый снимок, источники не читаются заново. Для 401/403 сохраняется прежний отдельный путь отказа: предыдущие бизнес-данные не подмешиваются.
