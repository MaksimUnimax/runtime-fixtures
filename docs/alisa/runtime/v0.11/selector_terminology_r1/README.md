# B08.finance_sales: пояснение для выбора

Прямое правило владельца от 10.11.2026: «для ИИ», «для DeepSeek», «для дипсика» означает помощь в выборе шаблона (`purpose`); «для Алисы» означает примечания для модели, формирующей озвучиваемый ответ (`notes`). Правило закреплено в [OWNER_TERMINOLOGY.md](../../../OWNER_TERMINOLOGY.md) и указано в навигации документации Алисы.

В B08.finance_sales версия 4 переносит пояснение из notes в purpose. Новый purpose:

> Продажи до удержаний. Ozon: товарные начисления в цене продавца, с баллами за скидки и партнёрскими начислениями. WB: сумма продаж финансового отчёта. Не сумма оформленных заказов и не итог начислений.

`notes` теперь пустой список. Команда «называй…» не добавлялась. Исполняемые обработчики, расчёты, источники, общие промпты и остальные шаблоны не меняются.

База: alisa-raw-template-flow-r1-20261110, source 6ae53c9d84e34faec0f2d39ff19d83f84a5067e0. Новый релиз: alisa-selector-terminology-r1-20261110. Полный каталог однозначно восстанавливается применением template_patch.json к базе; в нём зафиксированы SHA256 исходного и итогового каталога.

Проверка: 76 существующих проверок шаблонов, включая составные, изоляцию notes от выбора, только выбранные notes в ответе, повторы и права. Дополнительно verify_payload.py проверяет полный существующий сценарий finance_sales: пояснение присутствует у модели выбора, отсутствует среди примечаний итоговой модели, исходный вопрос и данные API сохранены, два модельных вызова-фикстуры. Живые обращения и колонка не используются.

Установка использует новую директорию, проверку активной базы, хешей и отсутствия выполняемых заданий; исходный релиз не редактируется. STOP голосовых тестов сохраняется. Сокращение служебной фразы приёма — ранее запрошенная отдельная правка, этим изменением не объявляется выполненным.
