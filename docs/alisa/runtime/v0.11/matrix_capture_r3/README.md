## Что изменено

В общем графе исправлены JSON-проекции, без изменения Python-файлов runtime и расчётного слоя:

- FBO использует `created_at`, FBS — `in_process_at`. Ненужная дата другой схемы больше не захватывается. Отсутствие нужной даты не подменяется альтернативной.
- `unit_number` обязателен для начисления с `posting` или `item_fees`. Для записи, у которой оба блока явно null, ссылка не применяется и сохраняется null. Дата и полная сумма записи остаются в контролях; неизвестные денежные значения не превращаются в нули. Отсутствие маркера варианта также не замалчивается.
- Общий каталог ошибок объясняет `BINDING_MISSING` как отсутствие необходимого поля, без вывода сырых диагностик и без автоматического повтора API.

[Точное описание JSON-дельты](CAPTURE_DELTA.json). Полный unified patch находится в архиве как `MATRIX_CAPTURE_R3.patch`. Дата запуска и границы квалификационного примера вынесены в проверяемый план canary; это тестовый инструмент, не изменение production authority.
