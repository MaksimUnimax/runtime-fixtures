# Короткая стартовая реплика Station

**Заменено station_ack_eta_r2:** вариант «только секунды» не соответствует уточнению владельца. Актуальная реплика сохраняет подтверждение задания и динамическую ETA, удалена только фраза о колонке. См. [исправление](../station_ack_eta_r2/README.md).

По прямому требованию владельца длинная реплика принятия задания заменена на **только рассчитанное время в секундах**. При оценке 30 секунд ответ — `30 секунд.`; слов о колонке нет. Значение ETA берётся из существующего расчёта, не фиксируется на 30.

Изменена одна продуктовая строка service.py. end_session=True, очередь, таймеры, состояние/авторизация и точная выдача READY-ответа сохранены. Общие промпты моделей и ядро не меняются.

База Station: station-raw-template-flow-r1-20261110. База wrapper: 20261110-raw-template-flow-r1. Зафиксированное ядро: alisa-wb-buyout-choice-v3-20261110 / a2d20c84ba3b1bd94aebf53b2f9b890a00927f1a.

**60 проверок PASS под alice-lab**, включая полный raw webhook → end_session → READY → callback → точный ответ; отдельно проверены стартовые 60 и 30 секунд. READY-ответы не сокращаются этим изменением. Первый запуск тестов выявил отсутствие обязательного ALISA_RAW_FLOW_CORE в окружении тестера; после задания актуального ядра полный набор завершился без ошибок/пропусков.

Установщик использует существующий rollback/health flow, переключает только Station и web-wrapper между завершёнными вопросами, сохраняет ключи/состояние и фиксированное ядро. При новом активном задании откат откладывается. Удаляются только собственные записанные override, чьи байты не изменились.

Фактическая установка фиксируется отдельной квитанцией. Голосовые проверки в этом исходном пакете не запускались.
