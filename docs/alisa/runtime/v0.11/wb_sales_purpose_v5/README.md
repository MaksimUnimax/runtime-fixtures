# B08.finance_sales: различение продаж WB и заказов

10.11.2026 владелец попросил уточнить для модели выбора: в вопросе «Сколько составили продажи Вайлдберриз до удержаний за восьмое ноября?» речь о продажах из финансового отчёта, не о сумме оформленных заказов.

Версия шаблона 4 → 5. `purpose` после изменения:

> Продажи до удержаний. Ozon: товарные начисления в цене продавца, с баллами за скидки и партнёрскими начислениями. WB: сумма продаж финансового отчёта, не сумма оформленных заказов. Не итог начислений.

`notes` остаётся пустым. Источники API, вычисление, первый и итоговый промпты, обработчики ошибок, исходный вопрос и составные зависимости не меняются. База: `alisa-selector-terminology-r1-20261110`, коммит `7f5af81dc6567f2ad30fb319adf4a528ad31eaad`. Полный каталог восстанавливается применением единственного `entries.B08.finance_sales` из `template_patch.json` к каталогу этой базы с проверкой двух SHA256.

Проверить перед установкой: активная база и манифест совпадают; изменение только `purpose` и `version`; успешно прошёл набор `test_template_only` и `test_template_integration`; нет выполняемых заданий и ожидающей доставки; при запуске модель получает новый `purpose`, а итоговый ответ прежний доступ к данным API и `notes=[]`. Установка в отдельный релиз под общим замком, старую базу не перезаписывать. Голосовой повтор этого вопроса после установки — отдельный следующий прогон.
