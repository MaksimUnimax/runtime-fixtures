# Краткие пояснения для выбора шаблонов

Обновляется только purpose и номер версии пяти обсуждавшихся шаблонов. Это текст первого вызова DeepSeek. Notes для итогового ответа и исполняемая логика не меняются.

| Шаблон | Точное новое описание |
|---|---|
| B01.ordered_revenue | Сумма оформленных заказов. Для «на какую сумму заказали». Не продажи и не итог начислений. |
| B06.finance_commission_cost | Комиссия Ozon за продажи с учётом её возврата при возврате товара. Для вопросов о комиссии; остальные услуги не входят. |
| B08.finance_sales | Продажи до удержаний. Ozon: в цене продавца, с баллами за скидки и партнёрскими начислениями. WB: сумма продаж финансового отчёта. Не сумма заказов и не итог начислений. |
| B08.finance_accrued | Итог начислений Ozon с учётом возвратов, комиссии и услуг. Для «сколько начислил Ozon». Не сумма заказов, не продажи до удержаний и не банковская выплата. |
| B08.finance_services_cost | Общая стоимость услуг Ozon: логистика, хранение, эквайринг и другие статьи услуг. Комиссия за продажи отдельно. Для «сколько стоили услуги/удержали за услуги». Для отдельной услуги — её шаблон. Не все удержания Ozon. |

По прямому указанию владельца тесты и платные/голосовые сценарии не запускаются. При установке проверяются только формат каталога, ограничение изменения полями purpose/version, манифест и активность службы. STOP сохраняется; simple-24 этим изменением не принимается.
