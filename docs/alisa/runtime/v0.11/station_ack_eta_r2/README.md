# Подтверждение задания и рассчитанное время без фразы о колонке

Исправлена неверная интерпретация указания владельца. Стартовая реплика сохраняет **«Задание принято» и существующее автоматически рассчитанное время**, а удалено только предложение «Сообщу ответ на этой колонке, когда расчёт завершится».

Шаблон: `Задание принято. Примерное время ответа — около {рассчитанное время}.`

Значение ETA не фиксируется на 30. Исходные baseline/history/label/таймеры не менялись. Примеры: при 30 сек — «Задание принято. Примерное время ответа — около 30 секунд.»; при 60 сек — «Задание принято. Примерное время ответа — около минуты.». READY-ответ модели сохраняется полностью.

Изменена одна продуктовая строка service.py, контрактные ожидания test_eta.py приведены к требованию. **60 локальных проверок PASS под alice-lab**, включая webhook/доставку и разные оценки ETA. Голосовые тесты после STOP не запускались и не разрешаются этой поставкой.
