# Алиса: закрытие повторного словесного разбора

Причина simple-25 была на сервере: DeepSeek правильно выбрал B08.finance_sales, но два последующих словесных фильтра отклонили выбор. Эти два фильтра исправлены предыдущим релизом alisa-template-basis-r1-20261110. Этот пакет закрывает остальные выявленные места в полном действующем пути.

| Место | Исправленное поведение |
|---|---|
| dialogue.py | В TEMPLATE_ONLY не запускаются старые словари выбора показателя, короткой даты, уточнений и исправления опечаток. Исходная command сохраняется без изменения; транзакционные квитанции, права и изоляция бесед продолжают работать. |
| alice_lab.py | Весь авторизованный пользовательский текст идёт в текущий исполнитель. Удалена лабораторная ветка с синтетическими ответами, её модельная зависимость и фиксированные пути к старым релизам ядра. |
| alice_bridge.py / local_gateway.py | Фасад больше не делит бизнес-фразы на старый/новый маршрут. Веб-клиент IPC не импортирует бизнес-логику из исторического релиза; авторизация и выполнение находятся в ядре. |
| Station service / station_client | Служебная доставка распознаётся общей точной грамматикой: вся команда с восьмизначным nonce. «Доставка за вчера на Озоне» проходит в модель. Проверки привязки, поколения, срока, nonce и квитанции сохранены. |
| Выход и выдача | «Выход» проходит через текущую отмену в своей беседе и закрывает сессию без модельного запроса. Статус «план запроса» понимает план шаблонов. Готовый ответ модели Station не переписывает даже при другом ручном ключевом слове. |
| template_runtime / TemplateGap | Только явное решение модели об отсутствии шаблона выдаёт TEMPLATE_NOT_FOUND и прежнюю точную фразу. Ошибка выбора/условий выдаёт TEMPLATE_EXECUTION_FAILED и честное сообщение об ошибке; первоначальные сведения остаются в существующем зашифрованном архиве. |
| Worker | Режим шаблонов выполняет корневые шаблонные задания и их проверенные внутренние фрагменты. Сохранённое старое задание больше не может обойти этот путь и вызвать прежний разборщик. |
| Тест всех 85 шаблонов | Проверка использует реальные purpose без подстановки «магических» финансовых слов; исправлено предыдущим релизом и повторно включено в общий прогон. |

Примечание B08.finance_sales сохранено без изменения: **Для Ozon «продажи» — товарные начисления до удержаний, а не оформленные заказы.** Остальные определения и допуски шаблонов этим пакетом не редактируются.

Архитектура: исходный вопрос → модель выбирает зарегистрированный шаблон → сервер получает данные и выполняет расчёт по шаблону → исходный вопрос, данные API и примечания выбранного шаблона передаются итоговой модели → свободный текст передаётся в Алису. При успешном сценарии два модельных вызова. Права, схема исполняемой команды, допуск источника и арифметика проверяются сервером; повторного выбора показателя по словам нет. Никаких преобразований чисел в слова кодом и новых речевых схем не добавлено.

## Проверки перед установкой

- 1895 проверок ядра, включая восемь новых сценариев исходного текста, коротких фраз, повторов, запрета старых заданий, ошибок выбора, просмотра плана и выхода.
- 87 дополнительных проверок наборов данных.
- 60 проверок Station и веб-входа, выполнены под alice-lab без пропущенных проверок. Семь новых проверок включают настоящий локальный Unix IPC в ядро, очередь, API-фикстуру, итоговую модель-фикстуру и callback выдачи. Повтор исходного сообщения и повтор callback не создали дополнительных модельных/API-вызовов.
- Сохранены проверки 429/503, отозванного доступа, OAuth/WAL, отмены, нескольких бесед, выбранных примечаний и учёта фактических вызовов модели.

Всего **2042 проверки прошли**. Это офлайн-проверки с фикстурами; платные вызовы и воспроизведение на колонке не запускались. Окончательный факт установки подтверждается отдельными квитанциями, а не этим описанием.

## Установка

Исходная база ядра: alisa-template-basis-r1-20261110. База Station: station-auth-wal-r1-20261109, wrapper: 20261109-station-auth-wal-r1.

Новые релизы: alisa-raw-template-flow-r1-20261110, station-raw-template-flow-r1-20261110 и 20261110-raw-template-flow-r1. install_core.py и install_station.py проверяют тесты, хеши, активную базу и отсутствие активных заданий; создают новые каталоги и имеют возврат к исходному сервису при ошибке. Старые релизы не редактируются, пользовательские данные, ключи и права не переписываются. Общая блокировка конфигурации сохранена.

Голосовой тест simple-25 после прежнего отказа остаётся не допущенным до реального прослушивания владельцем. Голосовая серия приостановлена на время исправления.

Установлены все три новых релиза из коммита 6ae53c9d84e34faec0f2d39ff19d83f84a5067e0. Проверены манифесты и активные пути процессов, три службы active/running, веб-вход healthz HTTP 200. После установки повторены восемь прицельных проверок ядра и семь сквозных проверок веб/Station на установленных файлах. Это повтор ранее учтённых сценариев, а не ещё пятнадцать уникальных тестов.

Все перечисленные в предыдущем аудите дефекты действующего шаблонного пути закрыты. Старые реализации других режимов не служат fallback для TEMPLATE_ONLY; отдельная проверка запрещает выполнение старого корневого задания в этом режиме.

В новой сквозной фикстуре также исправлено создание временного каталога и чтение задания по ID своей беседы.
