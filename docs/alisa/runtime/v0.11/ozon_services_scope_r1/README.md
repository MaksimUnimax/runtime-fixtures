# Комиссия и общая стоимость услуг Ozon

Основание: уточнение владельца после принятия simple-23, 09.11.2026. В порядке принятия запрос № 6 — «Сколько потратили на комиссию вчера на Озоне?», № 17 — «Сколько стоили услуги Озона вчера?».

| Шаблон | Что считает | Источник |
|---|---|---|
| B06.finance_commission_cost, версия 2 | Комиссию за продажи с учётом сторно комиссии при возвратах | Отрицательная сумма cashflows.sales.fee и cashflows.returns.fee |
| B08.finance_services_cost, версия 2 | Общую стоимость всех строк раздела услуг; состав определяется ответом API за период | Отрицательная сумма amount всех строк cashflows.services |

В разделе услуг могут быть логистика и обратная логистика, хранение (размещение товаров на складах), эквайринг и другие статьи. Комиссия за продажу извлекается из отдельных полей и в итог услуг не входит. Итог услуг и его отдельные части нельзя повторно складывать.

Обновлены purpose обоих шаблонов: селектор видит различие между комиссией и суммарной стоимостью услуг. Для B08 добавлен notes: итог и период, одно короткое пояснение состава, комиссия отдельно; фактическими называются только статьи из полученных данных. notes передаётся только итоговой модели при самостоятельном выборе этого шаблона. Составной шаблон продолжает получать исключительно собственные комментарии.

«Сколько удержали за услуги Ozon вчера?» соответствует B08.finance_services_cost. «Сколько удержали комиссии за продажи Ozon вчера?» соответствует B06.finance_commission_cost. Фраза «удержания Ozon за вчера» без состава шире одного из этих показателей: ни комиссия, ни услуги сами по себе не доказывают покрытие всех удержаний. В текущем временном протоколе нет отдельной команды уточнения: при непокрытом вопросе используется существующая ветка unsupported. Эта правка не добавляет обработчик уточнений или новый шаблон всех удержаний.

Изменение только данных каталога: version/purpose у комиссии, version/purpose/notes у услуг. Расчётные поля, API-запросы, обработчики, три общих промпта и 83 других шаблона сохранены. База — установленный alisa-report-archive-r1-20261109: параллельно добавленный архив отчётов также сохраняется.

template_patch.json содержит точный исходный/новый SHA256 и две обновлённые записи. Накладывается на совпадающий каталог, существующие релизы не перезаписываются. Проверка: существующие 75 тестов выбора/исполнения/передачи комментариев, разбор каталога и семантическое сравнение разрешённых полей. Эти проверки подтверждают передачу данных, а не безошибочность вероятностного выбора модели. Новые платные запросы и голосовые сценарии после STOP не запускаются; формулировка ответа с пояснением требует последующего прослушивания владельцем.
