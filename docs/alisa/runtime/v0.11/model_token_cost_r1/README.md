# Расход токенов и стоимость пользовательского запроса

По распоряжению владельца от 09.11.2026 к отчёту каждого прогона добавляется расчётная стоимость DeepSeek в рублях. Для согласованных шаблонов стоимость сохраняется в списке приёмки вместе с датой, временем выполнения, числом вызовов и основанием пересчёта. Старые прогоны без usage не получают выдуманную цену. Составной запрос имеет одну общую цену прогона с перечнем выбранных шаблонов; эта сумма не объявляется отдельной ценой каждого компонента.

## Источник и хранение

Рабочая модель запрашивается как `deepseek-flash` непосредственно у api.deepseek.com. Прежний транспорт сохранял только content/finish_reason, отбрасывая usage. Теперь только модельное имя и числовые счётчики исходного ответа сохраняются в nullable-поле `calls.model_usage` существующего журнала. Тексты вопросов, ответов, рассуждений, ключи и полный HTTP-ответ сюда не попадают. Срок хранения — семь дней; удаляется целиком прежними правилами очистки calls. Старые строки остаются с NULL.

При успешном ответе usage сохраняется до локальной бизнес-транзакции: отказ валидации содержимого не удаляет уже полученный расход. Если JSON ответ содержит usage, но не содержит правильного choices, расход передаётся с CallError и тоже сохраняется. HTTP-ошибка без usage, потерянный ответ, сбой JSON или авария до записи оставляют стоимость этой попытки неизвестной. Запрос не повторяется только ради выяснения стоимости. Незавершённые и неизвестные попытки не выдаются за нулевые расходы. Повторы сохраняются как отдельные строки прежнего журнала.

## Расчёт

`model_usage.job_attempts(repo, job_id)` возвращает только реальные отправленные модельные попытки за семь дней. `price_attempt(receipt, input_cached=..., input_uncached=..., output=..., rub_per_currency=...)` считает Decimal по тарифам за миллион токенов. Тариф и курс передаются явно, вне бизнес-логики ответа. При неизвестном расходе или противоречивых счётчиках функция возвращает None.

Цена = (вход из кэша × тариф кэша + новый вход × тариф входа + выход × тариф выхода) / 1 000 000. Затем перевод в рубли. completion_tokens уже включает рассуждения; reasoning_tokens второй раз не прибавляется. Цена пользовательского запроса — сумма его оплачиваемых вызовов, включая повторы с известным usage. Если часть usage неизвестна, показывается известная сумма и отметка неполного расчёта.

Тариф выбирается по модели и времени каждого вызова; его источник и дата проверки фиксируются вместе с расчётом. Валютный пересчёт по опубликованному курсу — расчётная оценка, не заявление о фактическом списании с банковской карты или комиссии пополнения. Нельзя применять один текущий тариф к старым вызовам после смены цен/модели или к вызовам разных тарифных часов.

Официальные источники, проверены 09.11.2026:
- https://api-docs.deepseek.com/api/create-chat-completion/
- https://api-docs.deepseek.com/quick_start/pricing/
- https://www.cbr.ru/currency_base/dynamics/

На момент проверки off-peak USD / 1M для deepseek-flash: cache hit 0.003, cache miss 0.15, output 0.60. Peak вдвое дороже; расписание и исключения праздничных дней берутся из официального тарифа. Эти числа не зашиты в исполнение или шаблоны.

Механизм выбора шаблонов, два обычных модельных этапа, промпты, API-контракты, политика 429, доставка и содержимое ответов этой правкой не меняются. Дополнительного обращения к модели нет. Самостоятельный новый голосовой прогон не запускается.
